# Camera vision service: assumptions

What `broker/vision`, `broker/vision/supervise` and `broker/cmd/agentos-vision` rest on (briefs/VIS-core.md; part (a), VIS-svc). Each row is a reading of the brief or spec, or a property the code relies on, that a reviewer may want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| VIS-A1 | Part (a) links no runtime, as INFER-A1: `agentos-vision` built from it answers every call Unavailable, and the tests use a fake runtime. Part (e) adds `runtime_<name>.go`, the models and their pins; part (f) starts the service from agentosd. | brief split (a), (e), (f) | Nothing reaches the service before (f) wires it. |
| VIS-A2 | The service returns no track id, although the brief's design point 2 lists one. Tracking runs in the client (point 2, later; part b), and a service-chosen number per detection would be one more field a compromised service could fill with bits. | DEV-7; brief point 2 | If (b) needs the service's own association (for example appearance cues), it gets a closed signal (same or new, per previous box), never a free integer. |
| VIS-A3 | Confidence is an integer percent from 1 to 100. That is the brief's "quantised to two decimals" held exactly: a JSON float such as 0.87 cannot be checked for two decimals without rounding, and an integer can. | brief point 2 | None; a consumer that wants 0 to 1 divides by 100. |
| VIS-A4 | An error reply carries a cause from the four and no detail. INFER-SVC passes a cleaned detail through; here that would be 200 bytes of service-chosen text per call reaching a log, which is a channel for an encoding. The client's own `Error.Detail` is fixed text it writes. | DEV-7, A16 as amended by #3497 | A cause the owner needs to see is added to the closed list. |
| VIS-A5 | The supervisor sends the service's stdout and stderr to /dev/null (`QuietChild` in infer/supervise), and its own lines name the service (`Name`). Its STATUS cause stays the exit status and the oom mark, which the supervisor writes, not the service. A panic trace from the service is lost with the rest of its output. | DEV-7; INF-8 | Diagnostics the owner needs come back through the protocol's closed causes, never through the service's text. |
| VIS-A6 | vision/supervise reuses infer/supervise's jail, leaf and restart loop rather than copying them, adding only the two options above. The service runs as its own user (part f adds `agentos-vision`), never as agentos-infer's, because it will hold templates (part c). | RES-2; brief point 1 | A jail difference between the two services goes into infer/supervise as another option, so the two never drift. |
| VIS-A7 | A frame is decoded pixels (rgb24, gray8, or y16 for thermal) sent raw after a JSON header line, not base64 on the line: CAM-clerk delivers decoded frames, and base64 would cost a third more bytes and an encode per frame on the N95. The largest frame is 3840x2160 rgb24 (about 24 MiB); the service holds at most `-concurrent` payloads (2 by default): it reads a payload only once a slot is free, and a runtime call that outlives its deadline keeps its frame and slot until it returns (a timeout reloads the runtime, which must make the call return), so neither a burst nor a hung runtime holds more than two frames. | RES-2; brief point 1 | Part (e) measures the floor; a smaller cap lowers `MaxWidth` and `MaxHeight`. |
| VIS-A8 | The class list (person, vehicle, dog, cat, bird, deer, fox, coyote, bear, unknown-animal) and the sound list (alarm, glass-break, gunshot, scream, dog-bark, vehicle, knock, doorbell) are fixed in code; changing either is a reviewed PR. There is no speech label. | DEV-7; brief point 2, Mark 2026-10-27 (sound events only) | Part (e) may narrow the lists to what its models can tell apart; widening them is a reviewed change. |
| VIS-A9 | Plate text (`[A-Z0-9 -]{1,10}`, no space at either end) is a residual channel: about 50 bits per vehicle detection. Raw detections reach only the tracker, the owner's page and the drone fixes; planners and the bus see rate-limited track outputs (part b, DEV-8). | DEV-8; brief point 2 | (b)'s events carry plate text only quoted (`QuotedPlate`), and only for a vehicle on a consistent track. |
| VIS-A10 | `Client.Enrolled` comes from the client's own `clerk.Secrets` slots (part c); in part (a) it is nil, so every `enrolled:<id>` reply is refused, and the service, which has no templates yet, checks its runtime with no ids. | DEV-7 | None. |
| VIS-A11 | The leaf, OOM, jail and quiet-output tests skip off root or without a delegated cgroup; CI's machines step runs `./vision/...` with `./infer/...` as root with no_new_privs and fails on any skip (INFER-A8). | RES-2 | As INFER-A8. |
