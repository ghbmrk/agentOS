# Assumptions: the device-driver host library (DEVSLOT-drivers part b2a, #3472)

What the package rests on. Brief: `briefs/DEVSLOT-drivers.md` ("Part (b), settled"); decision D-189. The wire and the process entry are in `broker/clerk/devslot` (DEVSLOT-host-lib-1 to -3).

| ID | Assumption | Serves | If wrong |
|---|---|---|---|
| DEVSLOT-host-lib-4 | **The host re-checks everything, outside the driver's address space.** It holds the image's declaration (from `drivers.json`, part b1), never the driver's, and compares the declaration the driver's process sends with that one's `Canonical` bytes; it never parses the driver's. It refuses an operation the image lacks before any process starts. Every write must be one of the running operation's shapes on its declared channel (`Declaration.Writes`), so an undeclared, oversize or wrong-channel frame never reaches the transport. Every frame the device sends must come from the pin on a declared channel and be at most `MaxRead`. A refusal fails the operation, closes its connection and emits nothing. The slot's own checks in the driver's process are a second layer (DEVSLOT-a-7). | DEV-1, DEV-4, CLK-1 | none |
| DEVSLOT-host-lib-5 | **The host owns the transport.** `Config.Transport` is the slot's `Transport` interface, called only by the host: the key-checked TCP stream is b2b's, the enforcer's GATT relay is part c's, and until then GATT is a fixed "no relay" error (b2b). A transport error crosses the wire only as `failed`, and the driver may go on; no device or transport text reaches the driver or the log. | DEV-2, DEV-3, NET-2 | none |
| DEVSLOT-host-lib-6 | **Each operation is one connection and one deadline.** `Do` dials the driver's socket unit (`Dialer`), which starts a fresh instance (Accept=yes), and closes the connection at done, refusal or deadline; `Config.Deadline` bounds dial to done, and the unit's `RuntimeMaxSec` kills a process past it (part b1). One operation runs at a time per driver. | CLK-1, RES-2 | none |
| DEVSLOT-host-lib-7 | **Readings are checked and held until done.** A reading must be a kind the image declares, with an exponent in [-18, 18] and a time in canonical RFC 3339 form in UTC (`Z`, no offset, zone name or trailing zeros), at most `MaxReadings` per operation. Readings are emitted only after a clean `done`, so a refused one emits none. Events carry the image's device and operation names, the `private` label, and `Unverified` unless the link is TCP (DEV-3). | DEV-8, PLN-3 | none |
| DEVSLOT-host-lib-8 | **One host is one source for DEV-8.** A host serves one driver for one pinned device. Its first `Limit.Burst` events of a window (from the window's first event) go to the sink; the rest are counted, and the count goes out as one `Coalesced` event carrying the last reading once the window has ended, on the next event or on `Flush`, which b2b's process calls on a timer. The limit's values are b2b's configuration. | DEV-8, RES-1 | A source needs limits per reading kind: key the window by kind. |
| DEVSLOT-host-lib-9 | **The host is a parser of hostile bytes.** It decodes the driver's wire messages (through `devslot.ReadMsg`) and checks the device's frames, so it has a `parser` line in `tools/trusted_base_parsers.txt`. Nothing links it into a binary before b2b (`cmd/agentos-devices`). | KRN-2 | none |
