# clerk/readerwire assumptions

Built for MAIL-reader-sock-a (#3421, briefs/MAIL-reader-sock.md). Each row is a reading a reviewer may want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| MAIL-reader-sock-a-1 | **Only the canonical encoding of a call or an answer is read.** Each end decodes a line and refuses it unless `encoding/json` encodes the value back to exactly the same bytes, so another key case, an unknown or duplicate key, other spacing or another escaping is refused rather than read. Both ends are this package, so the canonical form is the only one either sends. Any byte after the line's newline is refused too. | D-154 rule 1 | A reader in another language would need the same encoder, or a stricter decoder here. |
| MAIL-reader-sock-a-2 | **A reply past the bound fails only that mail; a reader failure pauses every mail for a minute.** The mail can steer the model's reply, so the reader answers a reply over 64 bytes, or one that escaping grows past the 256-byte answer, as `too-large`, which the mail clerk does not count as the reader's failure; a lying reader's over-long or malformed answer is refused the same way. A dial error, a wrong uid, the reader's own deadline, a lost answer, `unavailable` or `refused` pause the next calls for 60 s, with nothing dialled. A deadline or cancel of the caller's own context does not pause. | PLN-2, brief item 2 | If a mail can make the model clerk itself fail (a provider refusing its text), that mail pauses the read each time it is asked: slice b's model function should answer such a refusal per call, not as `unavailable`. |
| MAIL-reader-sock-a-3 | **The model function ends at the connection's deadline.** `Serve` gives each call a context with the connection's 60 s deadline and runs at most eight at once; a model that ignores its context holds its slot until it returns, though the mail clerk's own deadline ends the call on its side. Slice b's model function is one socket call under that context. | brief item 4 | Run the model in its own goroutine if a model function cannot honour its context. |
| MAIL-reader-sock-a-4 | **`Serve` checks no uid itself; `Listen` does.** The peer check is `sockets.ListenPeers`, so `Serve` on a listener from anywhere else admits any peer. `cmd/agentos-reader` (slice b) uses `Listen`. | D-154 rule 2 | none |
