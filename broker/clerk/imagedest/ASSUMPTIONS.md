# The kernel's own destinations (image statement): assumptions

Each row is a reading of the spec, or a property the code relies on, that a
reviewer may want to change (#6432, NET-2 Byte caps, D-248).

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| NET-2-image-daily-bytes-1 | **The statement is embedded in the binary, not a loose file under `image/`.** `go:embed` cannot reach outside the Go module (`broker/`), and the binary is itself part of the signed image's verity-protected `/usr`, so the figures change only with a signed release, as `accounts`' `known.json` does. A file installed through `image/mkosi/mkosi.extra` would add a runtime read that can fail and a second copy to keep equal, and sign nothing more. | NET-2 Byte caps ("the signed image states"), HW-10 | If the release signer must sign the figures apart from the binary, ship the file under `mkosi.extra` and give `Load` its bytes from there. |
| NET-2-image-daily-bytes-2 | **"The kernel's own destinations" are the hosts the core reaches for itself, not for an account:** today only the image's time sources (`broker/clock/chrony/chrony.conf`). The core has no online update source yet (`update.Source` is a mirror read through a directory or drive, DEP-4), so none is stated. `TestShippedStatesEveryKernelDestination` fails when the kernel's code (`kernel`, `cmd/agentos-kernel`, `cmd/agentosd`, `cmd/agentos-clock-boot`, `clock`, `update`, `follow`) gains a URL or host:port literal for a host the statement does not name, or chrony.conf gains a server or pool; it also fails on a stated host nothing reaches, since each stated host becomes a destination the owner signs. | NET-2 The core's list, TIM-1 | A host reached from a flag, environment or config file outside chrony.conf is not seen by the scan; add that source to the test when one exists (an online update mirror is the expected one). |
| NET-2-image-daily-bytes-3 | **Figures (proposals, for review).** Each NTS server (time.cloudflare.com, nts.netnod.se, ptbtime1.ptb.de) 2 MiB/day: an NTS-protected NTP request is about 230 bytes (48-byte header, unique-identifier, cookie and authenticator fields) plus 48 of UDP/IPv6 headers, at most about 600 bytes with placeholder cookies; chrony's default minpoll of 6 (64 s) gives at most about 1,400 requests a day with iburst, about 0.85 MB, plus NTS-KE handshakes (TLS on TCP 4460, about 1.5 KB sent each, at start-up and on cookie loss). The Debian pool 1 MiB/day: plain NTP is 76 to 96 bytes a packet, and `maxsources 4` at most 1,400 polls each is about 0.54 MB. The typical day is far below (polls back off to 1024 s, about 25 KB a server). [Inference] An NTS-KE retry storm while TCP 4460 is blocked sends only SYNs and stays inside 2 MiB. | NET-2 Byte caps (a cap is the stated figure, no margin) | A box that trips on a time source states a larger figure here, in a signed release. |
| NET-2-image-daily-bytes-4 | **One basis per host.** `Join` refuses a host both stated here and declared by an account (`*Shared`, naming it), so no cap is sized from two sources and an account cannot rename a kernel destination's figure. A declared destination claiming `Basis Image` is refused, since only this statement gives it. Duplicates inside the declared list are left to `enflist.Propose` (`ErrInput`) and `accounts.Load`. | NET-2 Byte caps, CLK-14 | — |
| NET-2-image-daily-bytes-5 | **The pool name is one destination.** chrony resolves `2.debian.pool.ntp.org` to up to four servers; the enforcer resolves the same name with its own resolver and allows the addresses it returns (NET-2 The core's list), so the cap is the name's, over all its addresses. NTS-KE may hand chrony an NTP server name other than the KE host; the three shipped servers return their own name. | NET-1, NET-2 | If a KE server returns another NTP host, that host is a destination the statement must name. |
| NET-2-image-daily-bytes-6 | **Pure and small.** The package does no I/O, decodes only its embedded statement and imports the standard library and `clerk/enflist`. Its one expected caller is the #5157 call site in `cmd/agentosd`, which passes `Table.Join(accounts' declared destinations)` as `enflist.Inputs.Dests`. | KRN-3 | — |
