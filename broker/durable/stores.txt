#
#   <dir> <kind> [debt:<ref>]
#
# kind is one of:
#   journal           the journal itself (OP-11's one log)
#   projection        a pure function of the journal, or a named cache of one
#   content           bytes the journal names: vault, snapshots, recall, logs
#   external-session  state an outside program changes itself (CRED-4, CRED-5)
#   config            owner or setup settings, not a lifecycle
#   debt              keeps a lifecycle beside the journal; <ref> names the
#                     audit section or issue that moves it off
#
# lifecycle_guard_test.go fails if a package that calls durable.WriteFile or
# durable.Rename, or renames under durable:exempt, is not listed here, and if
# a listed package no longer does. A new domain lifecycle is a journal intent
# kind (journal.Lifecycle), not a new line here.
