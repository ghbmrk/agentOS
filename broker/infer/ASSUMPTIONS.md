# Local inference service: assumptions

What `broker/infer`, `broker/infer/supervise`, `broker/cmd/agentos-infer` and the
agentosd wiring rest on (briefs/INFER-SVC.md). Each row is a reading of the spec, or
a property the code relies on, that a reviewer may want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| INFER-A1 | The package ships in two PRs at the brief's split. The first carries the protocol, client, supervisor, service and agentosd wiring against a fake runtime, with `-infer` off by default; no runtime adapter is linked, so `agentos-infer` built from it answers every call unavailable. The second adds the llama.cpp adapter (`runtime_llamacpp.go`, `real_test.go`), the image build, the service user and the `-infer-uid` flag in `agentosd.service` (INF-3), and the N95 step (INF-7). | INF-3, INF-7; brief "split at the checkpoint" | Turning `-infer` on before the second PR merges starts a service that only ever answers unavailable; nothing else changes. |
| INFER-A2 | The model file is image-owned and read-only to the service, so a change between the service's hash check and the runtime's read is not defended against. | INF-1, INF-6 | A model file the service user, or any non-root user, can write needs the runtime to load from the fd that was hashed instead. |
| INFER-A3 | The runtime serves embeddings without a TCP port (stdio or in-process); if it needs one, it binds 127.0.0.1 inside the child's own network namespace after bringing loopback up, which reaches nothing outside. | INF-6; brief assumption | The INF-6 test stays as it is; the supervisor's jail is unchanged. |
| INFER-A4 | The model's licence permits shipping it in the image (RECALL-EMB's assumption); the second PR verifies it before building, else stops and escalates. | INF-3 | No model in the image: the service stays off. |
| INFER-A5 | A user namespace with a one-uid map is available to agentosd on the target kernel, as loop7's jail already requires. Where it is not, every start fails and the service reports unavailable, never stopping the broker. | INF-1, INF-4 | A kernel without unprivileged user namespaces needs a jail built another way. |
| INFER-A6 | Two concurrent requests at batch 64 fit the 2.0 GB inference leaf with the 1.0 GB embedder figure (`Config.Concurrent` defaults to 2). INF-7 on the N95 confirms it or the cap drops. | INF-1, RES-2 | Lower the default `Concurrent`; the leaf's OOM kill reports `oom` and restarts meanwhile. |
| INFER-A7 | The leaf is the `inference` group `budget.Memory.Apply` creates beside the machine pool; agentosd finds it through the machine group it already opens, even when no runsc is configured, and starts nothing unless its `memory.max` equals the budget. It is not opened with `cgroup.Open`, whose subtree controllers would stop it holding a process. | INF-1, RES-2 | A budget layout that moves the component changes `inferenceLeaf` alone. |
| INFER-A8 | CI's machines job runs `./infer/...` tests that need a delegated cgroup only where it runs them; the supervisor's cgroup cases skip without one. Until that job lists the package, they run only on a host with delegation (finding: release). | INF-1 | Add `./infer/...` to the machines job. |
