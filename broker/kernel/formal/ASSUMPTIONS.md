# Formal model of the key rules: assumptions

Built for FRM-key (#2936). Covers `broker/kernel/formal/`, `broker/kernel/key/formal_test.go` and `broker/kernel/formal_hold_test.go`. Each row is a reading a reviewer may want to change.

| ID | Assumption | Spec basis | If it changes |
|---|---|---|---|
| FRM-key-a | **TLA+ with TLC, not Lean.** The rules are finite-state and the check is a pure function over small typed data, so exhaustive model checking of a bounded universe finds the same counterexamples a proof would rule out, with no proof to maintain when a rule changes; TLC is one pinned jar and needs only Java, which CI runners carry. The cost is that the result holds for the bounded universe (two further links, three times, three use counts), not for every chain length. The Go reference-model fuzz (`key/refmodel_test.go`) covers long chains at random. | KEY-1, KEY-3 | A proof for unbounded chains would be a Lean or TLAPS layer over the same definitions. |
| FRM-key-b | **The model abstracts what does not change a verdict.** Two verbs (one reversible, one irreversible), two labels, one caveat per link, signatures as the name of the signer. Argument bounds, content, spend and rate caps are left to the reference-model fuzz; `uses` stands for the counted caps, which all charge every prefix alike. | KEY-2 | Each further caveat kind is one more set in `Caveats` and one more case in `AddCav` and the Go switch. |
| FRM-key-c | **"Authority never widens without the passkey" is read as: no link widens, whoever signs it.** Only a new root or grant adds power, and only a passkey signs those (KEY-4); a root its owner did not sign, or any stranger-signed link, admits nothing. The model also accepts a looser `uses` link as harmless (evaluation is conjunctive), while the library refuses it as a loosening; the vectors pin the library's stricter answer. | KEY-3, KEY-4 | none |
| FRM-key-d | **"Labels only accumulate" is checked where the kernel can see labels today:** a chain's allowed labels only shrink, and adding a label to a step never turns a refusal into an admission. Label propagation through a plan's values (PLN-3) is not in `broker/kernel` yet, so it is not modelled. | PLN-3, KEY-2 | When value flow lands, add a propagation action whose labels are the union of its inputs'. |
| FRM-key-e | **Novelty is fixed when a step is held.** The hold model freezes it then, and its step property requires a held step's due time never to move earlier; the Go replay completes a same-shape step mid-hold to show the kernel agrees. | KEY-8, OWN-9 | none |
| FRM-key-f | **The committed key vectors are a sample** (every chain once in a plain context, then every 499th state, about 2.2k); CI's `formal` job writes all states (about 155k) and runs the Go tests on them, and fails if the committed sample differs from a fresh run. | KRN-6 | `SAMPLE` in `broker/kernel/formal/vectors.py`. |
