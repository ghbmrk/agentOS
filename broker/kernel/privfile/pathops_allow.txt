# Root-side path operations that pathops_lint_test.go lets through
# (REV-CHK-links, #3900). Two line forms:
#   allow <file> <func> os.<Call> <reason>
#     every use of os.<Call> in that top-level function (Type.Method for a
#     method) of that file; the reason says why no other uid can plant a link
#     on the path, and review checks it.
#   pending <dir> #<issue> <reason>
#     every use in that package's non-test files, until the issue's row ports
#     them; the line fails once the package has no use left to cover.
# A line that matches no use fails, so this file only shrinks as rows land.

# broker/sockets, cgroup, guest, loops, infer/supervise (#3944). unlink(2),
# rename(2), mkdir(2) and bind(2) follow no link at the final name, and
# os.RemoveAll descends with O_NOFOLLOW; only the last component is held by
# these lines (the lint's bound). cgroup2 (kernfs) has no symlink(2), so no
# uid, a delegate included, can plant a link among a group's files.
