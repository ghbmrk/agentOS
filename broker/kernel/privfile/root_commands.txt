# What a root unit under image/ or broker/ may run and set, pinned whole,
# read by pathops_lint_test.go (#4493, D-271). A unit is root as main's lint
# classes it (a User= absent, root or 0, holding $ or a % that may expand to
# root, a false DynamicUser=; a true DynamicUser= with no User= runs as the
# unit name's prefix), or when it has a + or ! line or a true
# PermissionsStartOnly=; a .socket that hands its socket to a root unit is
# root. Every command of a root unit is pinned here word for word, as its
# Exec value is written with no Exec prefix: "<unit> <command>". Every
# setting of a root unit whose key is on pinnedKeys is pinned here as
# "<unit> Key=value"; a key on inertKeys needs no pin, and a key on neither
# list fails. A line starting with a blank continues the entry above it.
# Each entry's reason is the comment block above it, which covers every
# entry below it up to a blank line. In a comment, a word +<path> names a
# program a pinned script starts, for the entry right below. Each word of a
# root-run pin that names a broker binary, bare or absolute, counts as
# root-side, and so does each +<path>. Review checks that a reason names
# every program its command starts. No pinned absolute word is reached
# through a link the image ships, /var/run, or a . or .. step. A pin no root
# unit uses fails.
