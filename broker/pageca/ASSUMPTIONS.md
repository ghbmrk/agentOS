# pageca: assumptions

Built for OWN-page-https slice a (#3153) against CH-9, HW-1 and §19 risk 30. `broker/pageca` is the core's page authority: a name-constrained root and its sealed key, held by agentosd only. Each row is a reading a later change could overturn.

| # | Assumption | Basis | If it changes |
|---|---|---|---|
| OWN-https-PCA1 | **One fixed name per release.** The page name is the same on every box (`DefaultName`, `agentos.internal`) and is configuration (`-page-name`) only so qualification can change it without code. The authority permits exactly that name and excludes its subdomains and every IPv4 and IPv6 address, critically; nothing is served on a subdomain. The Owner Card prints the name and the authority's fingerprint (a follow-on row; `Fingerprint` renders it). | CH-9, HW-1 | A name per box needs the card row to print it and the constraint to be made per box, which it already is. |
| OWN-https-PCA2 | **The authority's NotBefore is the image's build time less a day, never the clock**, and its NotAfter 30 years after that, so a wrong first-boot clock cannot stamp a root that phones refuse. A leaf's NotBefore is the later of the build time and a day before now, and its NotAfter the earlier of 825 days later and the authority's NotAfter. The build time is an input: until #3166 there is no caller, and #3166 passes the image's. | CH-9 | If the image has no build time, the caller must supply a fixed one per release. |
| OWN-https-PCA3 | [Inference] **Browsers treat an unlisted TLD as a public suffix** (the public suffix list's default rule), so `x.internal` and `y.internal` share no cookie scope, and the core's name and an enforcer's share no registrable parent (NET-4). Qualification shows it (G1). | CH-9, NET-4 | If a browser scopes cookies across `.internal`, the page needs a name under a registered domain. |
| OWN-https-PCA4 | [Inference] **iOS and Android enforce the critical name constraint on a user-installed authority, the excluded subdomain subtree included, and run WebAuthn with an RP ID under `.internal`.** Qualification on real phones shows it (G1); a platform that fails never gets the authority (CH-9). | CH-9, §19 risk 30 | A platform that ignores the constraint must not be offered the authority (slice b). |
| OWN-https-PCA5 | **No production sealer before STO-2 (#936).** `Store` seals the PKCS#8 key and the certificate under a `Sealer` with fixed AAD, writes them 0600 through `kernel/privfile.WriteAtomic`, and opens them with `O_NOFOLLOW` and an owner-only check, in a directory only this uid may write. Tests use `clerk.NewAESSealer` under a test key; no shipped binary passes a sealer, so a shipped agentosd has no authority and the page serves HTTP only until #3166 wires the real one. A claimed box never makes a new authority (`ErrRestore`): the card already carries the old fingerprint. | CH-9, HW-1, STO-2 | When STO-2's sealer lands, #3166 passes it and the claim state to `localsrv.OpenPage`. |
| OWN-https-PCA6 | **Imports.** The standard library and `kernel/privfile` only. `Sealer` is `clerk.Sealer`'s method set rather than clerk's own type, because clerk links crypto/tls and net/http, which agentosd's control path may not depend on (`daemon/arc2_test.go`); it uses `net` only for x509's IP ranges and `syscall` only for `O_NOFOLLOW`, `O_NONBLOCK` and `Stat_t` (`daemon/inference_test.go`). | ARC-2 | — |
