# Evaluation socket: assumptions

Built for integration step W3a (BOARD) on the replay evaluator (P3-1a) and the change pipeline (P3-1). Each row is a reading of the spec, or a gap left for a later package, that a reviewer may want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| E1 | **Process boundary.** The change pipeline and the loop scheduler link network clients, so ARC-2 keeps them out of `agentosd` (loops L16). The machine manager stays in `agentosd`, so the evaluator runs there too, and this socket is the one seam: `Client` is the pipeline's `change.Evaluator`, `Server` answers it with `replay.Evaluator`. | ARC-2, LOOP-5 | The arbitrator's PR2 split (dependency-free `route`/`update` types) would let the pipeline link into `agentosd`; this socket would then go. |
| E2 | **What crosses.** A request carries the tree, the probe (opaque ID and input), the probe's task (the journal intent its case was recorded on, from `Pipeline.ProbeTask`, empty for a security fixture), and the active tree under `ActiveNamespaces` only (`config`, `guest-image`, `host-image`, `routing`: what replay compares). `agentosd` reads recorded effects from its own journal (`replay.JournalRecordings`), so no journal data crosses. The answer is the guest's output, or `not_evaluated` (the client wraps `change.ErrNotEvaluated`, counted "Not tested on this box", never a pass), or `failed` (a failure on that side). Decoding is strict; a body is at most 32 MiB. | CHG-1, LOOP-5 | — |
| E3 | **Peer.** The socket admits one uid, the learning process's (`-learn-uid`), by SO_PEERCRED; other connections close unread. The learning process is broker code, so its request is trusted as the pipeline's word, like the egress sockets trust `agentosd`. `agentosd` serves no evaluations unless `-learn-uid` names a uid other than its own. | ARC-2, LOOP-5 | — |
| E4 | **One run at a time.** Runs are serialized, so the active tree and task the evaluator reads (`Server.Active`, `Server.Task`) are the run's own, and at most one replay machine holds memory. Another probe ID gets no task, so its effects fail closed. | RES-1, LOOP-5 | Per-run state if parallel evaluation pays on the N95. |
| E5 | **Model access off.** Replay's `Model` is nil, so runs are offline and a routing change is not evaluated (replay R2). W3b forwards replay machines' model calls to the learning process, where `loops.EvalModel` and the spare meter answer. | LOOP-5, OP-8 | W3b. |
