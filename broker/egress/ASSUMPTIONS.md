# Vault and credentialed egress: assumptions

Built for PLAN P1-3 against SPEC v0.12 (PR #15) on top of the broker
skeleton (PR #19). Covers `broker/vault` and `broker/egress`. Each row is a
reading of the spec, or a gap left for a later package, that a reviewer may
want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| V1 | The vault is one AES-256-GCM sealed file (stdlib only), names and values both sealed, replaced atomically, mode 0600. The 32-byte data key is supplied by the caller; wrapping it under TPM, passphrase, and recovery-key slots is P2-4. | CRED-1, CRED-8, DEP-1 | P2-4 supplies the key; the file format is versioned. |
| V2 | Only `egress` (and a future `cmd/agentos-egress` binary) may import `vault`; `vault/imports_test.go` enforces it. The daemon `cmd/agentosd` may not: it is on the ARC-2 control path. Inside the trusted broker process Go cannot hide memory, so custody rests on this import rule plus `Secret` formatting as a placeholder under every `fmt` verb, JSON, and text marshaling, including inside unexported struct fields (the bytes sit behind a pointer). `Close` zeroes the vault's own copies only; `Reveal` strings and redactor patterns are immutable Go strings. | CRED-1, ARC-1, ARC-2 | Add an importer only with a reviewed reason. |
| V3 | Values shorter than 12 bytes are refused, so CRED-7 redaction cannot shred innocent text. Passwords for credentialed browsers (P2-6) may need a different redaction rule. | CRED-7 | P2-6. |
| V4 | Redaction matches each value verbatim; as base64 (standard and URL-safe) at all three byte alignments, so a value inside a larger blob such as `base64("Bearer "+key)` is caught; as hex in any letter case; URL query and path escaping; and JSON string escaping. A value fully rewritten with arbitrary `\u` escapes, or split by a transform the redactor does not know, is not caught: redaction is defense in depth, custody does not rely on it. Streams hold back at most the longest pattern minus one byte. | CRED-7 | Add encodings in `NewRedactor`. |
| V5 | After `Close` every call fails (`ErrClosed`), so a late `Put` cannot rewrite the file with only the new entry. | CRED-1 | — |
| V6 | Rollback: an older sealed vault file still opens with the same key, so an attacker with the drive could restore a revoked credential. P2-4 binds a TPM NV monotonic counter into the AAD (or the sealed key slot). | CRED-8, REC-2 | P2-4. |
| E1 | Guest path is `/<adapter>/<upstream path>`. A request is forwarded only if the path is clean (no `.`/`..`/empty segments, nothing percent-escaped), has no query, and matches a declared operation's method and path template exactly. Everything else is denied with 403 and reported. No normalization: ambiguous means denied. | ADP-10 | Declared query parameters, and GraphQL/JSON-RPC body schemas, arrive with the first adapter that needs them. |
| E2 | Built-in relays declare inference only. OpenAI: `POST /v1/chat/completions`, the one route ARC-6 (a) qualifies. Anthropic: `POST /v1/messages`, declared but **not qualified** as a guest interface until a guest needs it (ARC-6 (a)); no grant should name it before then. `/v1/responses`, model listing, files, batches, key management, and billing are undeclared, so denied. | CRED-5, ADP-10, ARC-6 | Add an operation per qualified need. |
| E3 | Request headers are an allowlist (`Content-Type`, `Accept`, `User-Agent`, plus adapter-declared). An adapter may not declare `Location`, `Accept-Encoding`, `Content-Encoding`, `OpenAI-Organization`, `OpenAI-Project`, `Anthropic-Beta` (betas switch on server tools), or any name containing auth, key, token, session, cookie, secret, or password. So a guest's own key, cookie, org, or project header is dropped, and the vault credential is the only one sent. | CRED-5, A14 | Small: `credentialHeaders`. |
| E4 | The proxy sends `Accept-Encoding: identity` and refuses (502) any response with any other `Content-Encoding` value, in any header line or list, and sets `Content-Type: application/json` itself on rule-checked bodies, since compressed bytes would pass the redactor unread. Responses keep only allowlisted headers (`Location`, `Set-Cookie` never), redirects are returned rather than followed (the key is never re-sent elsewhere), and headers and body pass the redactor. | CRED-1, CRED-7 | Small: `baseResponseHeaders`. |
| E5 | Grants are a static machine → adapter table given at construction. The grant store and grant-change intents (OP-5) are a later package. Model access itself is ARC-6 (a) for any granted machine; the REV-5 data label, read from `Config.Label`, gates what the provider may fetch on the machine's behalf (E10). | OP-5, REV-5 | Swap `Config.Grants` for a lookup. |
| E6 | Decisions go to an `Auditor`, which `New` requires; events carry no header or body content. `JournalAuditor` (P1-7) journals denials as `egress` records (`journal.RecordEgress`: machine, adapter, operation, method, status, a redacted reason), outside any intent and never held by STOP. Per machine and reason, the first denial in a minute is journaled and the rest are counted into the next record's `suppressed`, so a looping guest cannot fill the journal. Allowed calls are not journaled one by one; the OP-8 meter counts them. | ADP-10 | — |
| E7 | Not linked into `agentosd`: only this package and `cmd/agentos-egress` may import the vault (V2), and nothing may unlock the vault before P2-4. So on the box the guest plane answers model calls with 503 until P2-4 runs the proxy in its own process behind each machine's model route. The guest plane (P1-7) serves `Proxy.Handler(machine)` on each machine's own socket, so identity comes from the listener; `e2e/a14_test.go` composes exactly that chain (vault, proxy, meter, guest socket) and is the A5 canary target. | ARC-2, ARC-6, CRED-1 | P2-4: a process holding the unlocked vault serves the model route. |
| E8 | OP-8 spend metering lives in `broker/meter`, applied by the guest plane in front of the model route, so every model call is counted by machine identity at the socket before this proxy sees it, and settled to the usage the provider reports (G7). The OpenAI relay forces `stream_options.include_usage` on streamed calls for that. The meter runs this handler on a context the guest cannot cancel and keeps accepting writes after the guest hangs up, so the upstream read finishes. `Config.Cap` stays as a second, hard per-machine ceiling, and `MaxConcurrent` (default 4) bounds one machine's requests in flight (each buffers up to 8 MiB). The default transport bounds connect (30 s), TLS handshake (10 s), and wait for response headers (10 min). | OP-8 | — |
| E9 | Every `Operation` declares an ADP-2 verb class from a closed list; `New` refuses an unlisted one. Only `read` operations are forwarded without an intent: any other verb is denied 403 until proxied effects submit a journal intent per call. Model inference is declared `read` (no effect on an external account). | ADP-10, ADP-2 | Submit an intent per call when the first effectful adapter arrives. |
| E10 | Relay bodies must be one JSON object. The proxy re-encodes what it checked, so no duplicate keys or trailing data reach the provider. `background` is always denied, and OpenAI bodies always get `store:false`. Provider-side fetches follow the calling machine's REV-5 label (arbitrator ruling). `BodyRule.PublicMayFetch` opts in, so a rule that leaves it unset is strict for every machine. Provider-side fetches are remote content sources (a non-`data:` string under `url`, `image_url`, `file_url`, `document_url`, `audio_url`, `video_url`, or `server_url`, anywhere outside JSON schemas and client `tool_use` input; e.g. OpenAI `image_url`, Anthropic `image`/`document` `source:{type:"url"}`), plus a `tools[]` entry whose `type` is not absent, `function`, or `custom`, plus `mcp_servers`, `container`, and OpenAI `web_search_options`. They are admitted only when `Config.Label` returns exactly `public`. A private or unknown label is denied. On the box `Label` is `vm.Manager.DataLabel`, which answers `public` only for a known machine labelled public and `private` for an unknown machine or any lookup error; no production proxy exists before P2-4, which constructs it with that function (`e2e/a14_test.go` checks the shapes match and uses the same contract). A nil `Label` makes every machine unknown, so all of them are denied. Anthropic client tools with schema-less types (`bash_*`, `text_editor_*`, `computer_*`) count as provider-side, which is stricter than needed. `Anthropic-Beta` is dropped for every label (an empty allowlist), so Anthropic server tools that need a beta flag do not work even for public machines yet. | ADP-10, REV-5, A14 | Admit a tool type or beta value only with a reviewed reason. |
