# The trusted core: the broker floor of briefs/SIM.md (ARC-1, D-095).
#
#   core <pkg>             a core package. tools/risk_tier.py rates it tier A.
#   wiring <pkg>           a composition root that builds and connects the core,
#                          so it may call write paths. Also rated tier A.
#   open <symbol>          a core function or method any package may call:
#                          a read, a pure helper, or the core's sanctioned
#                          interface. Every other function or method of a
#                          core package is a write path.
#   allow <pkg> <symbol> -- <reason>
#                          one named non-core caller of a write path, and why.
#
# <pkg> is a directory under broker/. <symbol> is pkg.Func, pkg.Type.Method,
# pkg.Type.* or pkg.*. broker/core/core_test.go fails when a package outside
# core and wiring calls a write path that no open or allow line covers, or
# declares an interface that a core type satisfies through one (wiring can
# then hand it the core type), and when a line names a package or symbol
# that does not exist. An interface finding names the package that declares
# the interface, which an alias elsewhere (loops.Journal = change.Journal)
# shares.

# Interfaces a core type satisfies through a write path (see the header).
# Authorize and Dispatch move an intent the caller already submitted through
# the gate's policy and the journal's dispatch; they run nothing the journal
# did not judge.
allow apply journal.Engine.Authorize -- apply.Journal moves the change intent it submitted through policy
allow apply journal.Engine.Dispatch -- apply.Journal dispatches the change intent it submitted once authorized
allow apply grants.Gate.Authorize -- apply.Journal is the grants gate on the box; same as journal.Engine.Authorize
allow apply grants.Gate.Dispatch -- apply.Journal is the grants gate on the box; same as journal.Engine.Dispatch
allow change journal.Engine.Authorize -- change.Journal (also loops.Journal) moves the intent it submitted through policy
allow change journal.Engine.Dispatch -- change.Journal (also loops.Journal) dispatches the intent it submitted once authorized
allow change grants.Gate.Authorize -- change.Journal is the grants gate on the box; same as journal.Engine.Authorize
allow change grants.Gate.Dispatch -- change.Journal is the grants gate on the box; same as journal.Engine.Dispatch
allow recalltool journal.Engine.Authorize -- recalltool moves the erase intent it submitted through policy
allow recalltool grants.Gate.Authorize -- recalltool's journal is the grants gate on the box; same as journal.Engine.Authorize
allow recalltool journal.Engine.Erase -- the owner's FORGET erases the journal records it names (recalltool.Journal)
allow recalltool grants.Gate.Withdraw -- FORGET withdraws an owner question about an erased intent as superseded (recalltool.Withdrawer)
allow photo/keep journal.Engine.Authorize -- the photo store moves the receipt, delivery and deletion intents it submitted through policy (keep.Journal)
allow photo/keep journal.Engine.Dispatch -- the photo store dispatches the intent it submitted once authorized (keep.Journal)
allow photo/keep journal.Engine.Erase -- an owner photo deletion or expiry erases the photo's intents' content (CAP-3, keep.Journal)
allow control journal.Engine.Stop -- the owner's STOP text (control.Engine)
allow control journal.Engine.Resume -- the owner's code-checked RESUME text (control.Engine)
allow control guest.OwnerAgent.Deliver -- owner chat goes to the owner's agent machine (control.Agent)
allow loops journal.Engine.RecordQuality -- Loop 1 records the quality signal on a finished intent (loops.JournalReader)
allow modelroute journal.Engine.RecordEgress -- each routed model call leaves its egress note (modelroute.Recorder)
allow provagent journal.Engine.StopRoute -- a refused login stops the provider's route in the journal, so it stays stopped across a restart (CRED-5, OP-11; provagent.RouteStops)
allow provagent journal.Engine.ReopenRoute -- the owner's stored sign-in reopens a route only while it is stopped for a refused login; the journal refuses the reopening for any other cause (CRED-5, CRED-RS-5; provagent.RouteStops)
allow vm guest.Plane.Open -- a machine's sandbox opens its own guest socket at creation (vm.Services)
allow vm guest.Plane.Close -- and closes it when the machine is destroyed (vm.Services)
allow vm guest.Plane.Reset -- and drops the tool results it held for the machine when a forget resets it (vm.Resetter, CAP-3)
allow recall journal.FileStore.Append -- shape only: recall.Store matches the journal's store, and wiring gives recall its own FileStore
allow recall journal.FileStore.Rewrite -- shape only: as journal.FileStore.Append
allow recall journal.MemStore.Append -- shape only: as journal.FileStore.Append
allow recall journal.MemStore.Rewrite -- shape only: as journal.FileStore.Append
