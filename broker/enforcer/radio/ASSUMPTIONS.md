# Enforcer radio host: assumptions

Each row is a reading of the spec, or a property the code relies on, that a
reviewer may want to change (briefs/ENF.md slice k, #3669). Covers `radio/`
and `radio/confine/`; slice t's rows (ENF-t-*) cover its profiles there and
`radio/thread/`.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| ENF-k-1 | **The interface is a socket pair, not a path.** `confine.Start` hands the stack one end as fd 3, so the stack never opens anything of the enforcer's: the policy store and the page's socket stay in directories only the enforcer's user opens (0700), and the stack runs as its own user with no supplementary groups. `TestRadioCannotChangeRule` holds that for one layout of the enforcer's state; slice l owns the real layout (state partition, users) and must keep the policy store and page socket out of every stack user's reach. | NET-2 Confined radio stacks | If slice l puts the page's socket on a shared path, its directory must still exclude the stack users. |
| ENF-k-2 | **Declared ops are a closed table per stack (`radio.Declared`), checked twice.** `Host.Call` refuses an undeclared op, an unknown device, a characteristic the policy does not list for the device, or an out-of-bounds field before writing a byte; `Server.Serve` refuses the same on the stack's side, so a stack adapter cannot widen the interface by handling more. BLE declares read, connect, disconnect, write and subscribe, and no device verb: no first-release BLE device takes a channel command. There is no scan op that returns other devices and no raw HCI op. Slices q and t add their stacks' ops, each with a row in `TestOnlyDeclaredOps`. | NET-2 Confined radio stacks, Channel | A BLE device that takes a command adds the verb's op to BLE's row and the test's expected list. |
| ENF-k-3 | **The seccomp filter is the spike's deny list, the floor.** `confine` ports `spikes/ENF-radio`'s filter (no ptrace, mounts, namespace entry, bpf, modules, kexec, keyrings, perf, userfaultfd, cross-process memory, io_uring; `clone3` gets ENOSYS), refuses every new process (fork, vfork, and clone without `CLONE_THREAD`; ENF-k-12) and narrows `socket` and `socketpair` to the profile's families. BLE gets only `AF_UNIX`, for the system bus to BlueZ, so no IP, netlink, packet or raw Bluetooth socket. A per-stack allowlist from `strace -f -c` on hardware replaces the deny list later (spike README); this slice runs in CI only. | NET-2 Confined radio stacks, decision 6 | The allowlist becomes a per-profile list in `confine`, and the test adds a call outside it. |
| ENF-k-4 | **Each stack gets a fresh empty network and IPC namespace** (`CLONE_NEWNET`, `CLONE_NEWIPC`), so BLE sees only lo. Slice t's Thread and Matter profiles share one network namespace holding lo, `wpan0` and a dummy `infra0` (spike consequence 1); see ENF-t-1 and ENF-t-2. | NET-2 Confined radio stacks, D-231 | — |
| ENF-k-5 | **The launcher re-executes the enforcer's own binary to confine itself** (`confine.Trampoline`, first in main): Go cannot install a seccomp filter between fork and exec, so the child drops to the stack's user in the fork (`SysProcAttr.Credential`), then the re-executed binary refuses to go on as root or with supplementary groups, sets `RLIMIT_CORE` to 0 soft and hard (ENF-k2-mnt-d), sets no-new-privileges, installs the filter on every thread, and marks every descriptor above fd 3 close-on-exec (`close_range` with `CLOSE_RANGE_CLOEXEC`, so nothing the enforcer inherited without close-on-exec, such as socket-activation fds, reaches the stack), and execs the stack with an empty environment. A failure exits 126 before the stack runs. The stack's user must be able to execute the enforcer's binary (slice m installs it world-executable under `/usr`). | decision 6 | — |
| ENF-k-6 | **The stack is untrusted, so its answers end the link on any fault.** A frame that does not decode strictly (length 1 to 4096 bytes, JSON with no unknown field and nothing after it), an answer to no outstanding request or for another device, a code off the closed list, or a notification for a device or characteristic the stack does not serve closes the link, fails every waiter at once and kills the stack's process (ENF-k-11); nothing it sent is used. An answer that arrives after its request timed out, naming that request's device, is dropped and the link stays (a slow device costs no restart); more than 64 requests left unanswered past their timeout ends the link. Restarting the stack is slice l's. Go's JSON decoder matches field names without case and keeps the last of duplicate keys; both ends are this package, so that admits no request the checks would refuse. | NET-2 Confined radio stacks | — |
| ENF-k-7 | **Answers are bounded at 512 bytes** (`MaxData`), above a reading or a GATT value. A stack handler that returns more is answered `CodeFailed`. | — | Raise `MaxData` with the frame bound if a stack needs more. |
| ENF-k-8 | **`Host.Do`, `Host.State` and `Host.Send` wait at most `Config.Timeout` (10 s) for the write and the answer together**, under the channel's lock (ENF-d-7); `Send` also stops when its caller's context ends, and checks that context only once it holds the link's write lock (`wmu`), so a send queued behind a slow write whose context ends while it waits writes nothing (`TestSendChecksContextUnderWriteLock`). The write has a deadline (`Conn.SetWriteDeadline`), so a stack that stops reading fails its link instead of holding a caller (`TestStackThatStopsReadingCannotWedgeHost`); a caller queued behind a blocked write waits at most one more timeout. They never wait for a device challenge's answer from the core. `Attach` closes a replaced link's connection without taking its `wmu`, so a write already under way on the old link is not ordered against a relock on the new one; that is safe by construction, since `Attach` returns only once the replaced stack's process has been reaped (ENF-k-11). | ENF-d-7 | A shorter timeout if the channel's lock hold matters in slice n's measurements. |
| ENF-k-9 | **The BLE process itself, BlueZ's D-Bus client, is the follow-up row ENF-k2.** This slice builds the host, the confinement, the interface and BLE's profile and declared ops; the brief's estimate (110k) did not fit a D-Bus client as well, so it is split rather than half-built. | budget rule (split before starting) | — |
| ENF-k-10 | **Slice r's per-device secret release is not here.** Releasing a device's secret only to its own stack's process is slice r's (`devsecret::TestReleasedOnlyToOwnDevice`); it can hand the secret down this interface or a second fd at start. | STO-4 | — |
| ENF-k-11 | **A replaced stack's process, and every process it started, is gone before its new link attaches (#4311).** `Attach` takes the stack's process (`radio.Proc`, which `*confine.Proc` is) with its link, and refuses one whose `Pid` is not above 0: a nil `*confine.Proc`, which a launcher holds after a failed `Start`, would otherwise be taken and panic in the goroutine that stops it at the link's first fault, ending the enforcer (`TestAttachNeedsProcessAndLink`, #4521). Whenever a link ends (a fault, ENF-k-6, a failed write, too many unanswered, or a replacement) the host kills its process without waiting, since a caller may hold the channel's lock. `Attach` of a replacement ends the old link, then returns only once its process has been reaped; until then the stack has no link and a send gets `ErrNoStack`. So a timed-out unlock still unread in the old process's socket dies with it, and the relock on the new link is the last thing the lock hears (`TestReplacedStackGoneBeforeNewLink`). A stack starts no process (ENF-k-12), so no process of its own keeps its end of the interface; and since each stack is the init of its own PID namespace (`CLONE_NEWPID`), were one to get out the kernel would kill it when the stack dies, before the reap (`TestReplacedStackReapedAndStartsNoChild`). `Proc.Wait` and `Proc.Stop` reap once, and every caller returns only after the reap, with the stack's exit, so the launcher's own wait and the host's kill can run together (`TestWaitAndStopReapOnce`: two Waits blocked before Stop's kill, so a Proc that calls `exec.Cmd.Wait` twice fails every run, #4520). The guarantee stops at the stack's PID namespace: a request the old stack already handed to a process outside it (a D-Bus call queued in dbus-daemon or bluetoothd, a datagram already in Thread's shared network namespace) is ordered against the relock by those first-in-first-out queues, not by the reap; and a compromised stack could pass its interface descriptor out over the system bus or to a stack sharing its network namespace (Thread's to Matter, over an abstract socket), but such a stack can act on the radio directly anyway (NET-2 bounds it). Nor does its stderr hold the reap: a stack that passes its end of a stderr pipe out of its namespace is still reaped, and `Wait` closes the pipe a second later (`cmd.WaitDelay`; `TestStopReapsDespiteLeakedStderr`, #4521); a stack that exits 0 meanwhile is reaped with a nil exit, not `exec.ErrWaitDelay`, so the launcher never reads a clean exit as a failure (`TestCleanExitDespiteLeakedStderr`). The copy still waits on each `Spec.Stderr` write, so the launcher's writer must not block (slice l's log writer: a bounded buffer that drops, never a pipe to a reader that can stall). A process that cannot be reaped (stuck in the kernel) holds its replacement's `Attach` (each stack's attaches are ordered by a lock of its own, so another stack still attaches: `TestStuckStackHoldsOnlyItsOwnAttach`), which fails closed: that stack stays without a link. | NET-6, NET-2 Confined radio stacks | If slice l needs a bounded restart, `Attach` takes a context and refuses at its end, still never attaching early. |
| ENF-k-12 | **A stack starts no process, and is the init of its own PID namespace (#4521).** The filter refuses `fork`, `vfork` and `clone` without `CLONE_THREAD` (EPERM; `clone3` already gets ENOSYS, so libc falls back to `clone`), so a stack runs as one process with its threads: no child of its can outlive it, hold its interface or stderr, or leave an orphan. That is what a stack being init of its namespace needs: init reaps orphans, and a stack never has one. Every shipped stack fits: no view holds anything it could exec (every entry is noexec), the Go stacks never fork, and the pinned ot-daemon's only process calls are `forkpty`, whenever the radio URL's path is a regular file whatever its scheme (`HdlcInterface::Init`), and an `ExecuteCommand` nothing calls (measured on its static binary, 2026-11-02). `thread.DaemonArgs` takes the radio's path, not a URL, and makes the `spinel+hdlc+uart` URL from it, refusing a path that is not absolute, clean and plain, so the URL names no other file in the view (`ErrRadio`, `thread.TestDaemonArgs`); `confine.Thread` binds that path only as a character device, and the view fails the start of any other (exit 126, `confine.TestThreadRadioMustBeDevice`), so ot-daemon never reaches that `forkpty`, and the filter would refuse it anyway. The launcher must pass both the same path. The other duty, a default signal action, is the limit this row names: as init, a stack ignores every signal it has no handler for, whoever sends it: its own (a self-sent SIGTERM, or a SIGPIPE, which leaves its write returning EPIPE) and one from outside its namespace, the enforcer's or systemd's SIGTERM included; only SIGKILL and SIGSTOP from outside, a SIGCONT, which resumes a stopped stack, and a fault (SIGSEGV, SIGBUS, SIGILL), act on it (`confine.TestStackIsInitOfItsNamespace`). So a stack is stopped by `Proc.Stop` (SIGKILL), never by a SIGTERM it may not handle, and slice l's shutdown must not wait on one. The PID namespace stays because it hides every other process from the stack, Thread's adapter runs as ot-daemon's user and could otherwise signal it, and it is the second wall behind the filter. The filter's rules are held by the interpreter model (`TestFilterDeniesEachEntry`), live (`TestFilterRefusesLive`: `fork` and a process `clone`; vfork by the model only, since its child would run on the probe's stack), and in the stacks (`TestStacksConfined`, `TestRadioCannotChangeRule`). The duty is confine's, not slice l's: slice l only launches through `confine.Start`. | NET-2 Confined radio stacks | A stack that must start a process gets a tiny init of its own in front of it, reaping and forwarding signals, reviewed as a widening of its profile. |
| ENF-t-1 | **Thread's user namespace is created by the enforcer as root** (`confine.Thread`, `NetAdmin`: `CLONE_NEWUSER` in the fork, mapping only the stack's own uid and gid), never by the stack, so the enforcer image can set `unprivileged_userns_clone=0` (KERNEL-trim part b, #4094). In it ot-daemon holds `CAP_NET_ADMIN` and `CAP_NET_RAW` as ambient capabilities, which act only on its own network namespace (a tun `wpan0`, its addresses and routes, raw ICMPv6 for border routing); it is not uid 0 there and has no other capability. The launcher holds the stack before its exec, brings lo up and creates `infra0` (a dummy link, up and multicast) over route netlink inside the namespace, then releases it; ot-daemon refuses to start without its infrastructure link. | NET-2 Confined radio stacks, spike consequence 1 | The enforcer's kernel must keep `CONFIG_DUMMY` and `CONFIG_TUN` and `/dev/net/tun` mode 0666 (Debian's default); a trim that drops them fails `TestSrpReachesController`. |
| ENF-t-2 | **The Matter controller joins Thread's network namespace and nothing else of it** (`Spec.Net`): the launcher starts it from an OS thread moved into that namespace, as its own user, with no capability and a fresh IPC namespace; a profile with `NetAdmin` or links cannot join (`ErrJoin`). `Start` takes a descriptor of its own for that namespace (`F_DUPFD_CLOEXEC`, so no concurrent fork inherits it), under the lock Thread's `Stop` closes its own under, so a link fault that stops Thread mid-join cannot hand Matter a closed descriptor, or a reused number naming another namespace; Matter then starts in the namespace Thread had, and a join after Thread's `Stop` is refused (`ErrNoNet`; `confine.TestJoinHoldsItsOwnNamespace`, #4521). Restarting Matter with Thread is slice l's. It reaches ot-daemon's SRP advertising proxy over mDNS on `infra0`, and Thread devices over `wpan0`. | NET-2 Confined radio stacks, spike consequence 1 | — |
| ENF-t-3 | **The deny list is one table, held to the kernel's.** `TestDenyListCoversKernel` reads the build host's `unistd_64.h` and fails if any namespace or mount entry point (by name: mount, the new mount API, `open_tree*`, `pivot_root`, `chroot`, `unshare`, `setns`) is missing or misnumbered; `open_tree_attr` (467), `statmount` and `listmount` joined. `TestFilterDeniesEachEntry` runs the filter program on a model of seccomp's interpreter and shows each entry is what refuses its call (a mutant without the line lets it through), which tells the filter apart from a kernel refusal for want of a capability (ENF-j delta L3, both findings). `TestFilterRefusesLive` shows the same live (#4233): a probe that is root of its own user, mount and network namespaces makes each namespace and mount call the stacks' probe claims, plus `umount2`, `chroot`, `fsconfig`, `fsmount`, `fspick`, `open_tree`, `move_mount` and `mount_setattr` (`pivot_root`, `open_tree_attr`, `statmount` and `listmount` have the interpreter model only); each succeeds with no filter and gets EPERM under the shipped one, and a synthetic filter without any one of those lines lets its calls through. A call the kernel refuses without the filter is reported `untested`, and fails the test. The stacks' own probe (`TestStacksConfined`) makes these calls in a single-threaded child and counts only EPERM as refused, since a threaded caller gets EINVAL from `unshare(CLONE_NEWUSER)` regardless of the filter. The CI runner's headers are older than the enforcer's kernel, so a call newer than them is caught when the image's headers are (slice m). | NET-2 Confined radio stacks | — |
| ENF-k2-mnt-2 | **Thread, its adapter and the Matter controller each see only their own files (#4369), as BLE sees only the bus (ENF-k2-10).** `confine.Thread` shows ot-daemon its state directory and its run directory (both writable: the network's dataset and keys, and its command socket, made in its working directory), the RCP's serial device, `/dev/net/tun` and `/dev/urandom` (its entropy, measured in the binary). `confine.ThreadAdapter` shows the adapter the run directory alone, read-only, so it reaches ot-daemon's command socket (a directory, not the socket, so ot-daemon's restart does not leave it a stale inode) and never the keys, though it runs as ot-daemon's user. `confine.Matter` shows the controller its storage directory alone; its Bluetooth commissioning goes through the BLE process over the radio host (Mark's pick, 2026-10-31), not a path. A view and NetAdmin share one user namespace, and Trampoline drops only CAP_SYS_ADMIN, so ot-daemon keeps CAP_NET_ADMIN and CAP_NET_RAW (`confine.TestThreadViewKeepsNetAdmin`, `TestStacksConfined`). ot-daemon is built static (`tools/build-openthread.sh`), so its view holds no loader; `TestSrpReachesController` runs it in that view on a simulated RCP whose pty is its serial device, as the enforcer's RCP is. Each stack's working directory must be in its view, or the start fails. Every entry is its real path: a radio named through a symlink such as `/dev/serial/by-id/…` fails closed (ELOOP), so slice l resolves it before the start. ot-daemon's view has no `/dev/log` (thread ENF-t-9). Every stack, not only Thread, is now held before its exec until Start has opened its network namespace, so one that exits at once cannot fail its own start (#4445 Security; `confine.TestStartHoldsUntilNetOpen` delays the open by a second and fails a release before it, #4477). | NET-2 Confined radio stacks | Slice l lays out the directories (the run directory 0700, owned by the Thread user) and passes the RCP's device; a stack that needs another file adds it to its profile, reviewed as a widening. |
| ENF-k2-mnt-d | **No stack dumps a core (#4459, confine part).** Trampoline sets `RLIMIT_CORE` to 0, soft and hard, before the exec; a stack has no `CAP_SYS_RESOURCE` over the host (Thread's capabilities are in its own user namespace), so it cannot raise it (`confine.TestStackDumpsNoCore`, run with the enforcer's own limit unlimited). So a crash of ot-daemon writes no core holding the network's keys into its run directory, which its adapter sees. The limit binds a core file; the kernel still hands a dump to a pipe `core_pattern` handler, which applies the limit itself or not, so the image's `core_pattern` (slice m) and the no-follow cleanup of stack directories (slice l) stay open on #4459. | NET-2 Confined radio stacks | — |
| ENF-k2-mnt-b | **A view entry is never reached through a symlink, and is the kind its profile declares (#4384).** Each entry (`confine.Entry`) names a kind: socket, directory, character device, or symlink (made in the view with the same target; only the tests' loader uses one). Trampoline opens it with `openat2(O_PATH\|O_NOFOLLOW, RESOLVE_NO_SYMLINKS)`, checks its type with `fstat`, and clones the mount at that descriptor, so a socket swapped for a symlink or a directory, or a symlink above it, fails the start (exit 126) instead of widening the view (`confine.TestViewRefusesSwappedEntry`). Every bind is nosuid, and the attributes are set on every mount under the entry too (a host submount included); nodev unless a device; read-only unless a writable directory; noexec unless the entry sets `Exec`, which only a read-only directory may and only `confine.Loader()` does (the tests' loader), so every shipped entry is noexec. Entries may not overlap. `ble.SystemBus` and `confine.SystemBus` stay two constants, since `ble` importing `confine` would link os/exec (childproc's gate); `ble.TestBusIsTheViewsBus` holds them equal. | NET-2 Confined radio stacks | — |
| ENF-k2-mnt-c | **The view's hardening steps are each held by a test (#4385).** `confine.TestViewOnlyItsEntries` shows a mount the host makes under a shared entry after the start does not reach the stack (the namespace is made private before the clones), the stack's mount table has one mount at `/`, the view's tmpfs (the old root detached after `pivot_root`), and each entry's mount carries its attributes (statfs flags).
