# Enforcer radio host: assumptions

Each row is a reading of the spec, or a property the code relies on, that a
reviewer may want to change (briefs/ENF.md slice k, #3669). Covers `radio/`
and `radio/confine/`; slice t's rows (ENF-t-*) cover its profiles there and
`radio/thread/`.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| ENF-k-1 | **The interface is a socket pair, not a path.** `confine.Start` hands the stack one end as fd 3, so the stack never opens anything of the enforcer's: the policy store and the page's socket stay in directories only the enforcer's user opens (0700), and the stack runs as its own user with no supplementary groups. `TestRadioCannotChangeRule` holds that for one layout of the enforcer's state; slice l owns the real layout (state partition, users) and must keep the policy store and page socket out of every stack user's reach. | NET-2 Confined radio stacks | If slice l puts the page's socket on a shared path, its directory must still exclude the stack users. |
| ENF-k-2 | **Declared ops are a closed table per stack (`radio.Declared`), checked twice.** `Host.Call` refuses an undeclared op, an unknown device, a characteristic the policy does not list for the device, or an out-of-bounds field before writing a byte; `Server.Serve` refuses the same on the stack's side, so a stack adapter cannot widen the interface by handling more. BLE declares read, connect, disconnect, write and subscribe, and no device verb: no first-release BLE device takes a channel command. There is no scan op that returns other devices and no raw HCI op. Slices q and t add their stacks' ops, each with a row in `TestOnlyDeclaredOps`. | NET-2 Confined radio stacks, Channel | A BLE device that takes a command adds the verb's op to BLE's row and the test's expected list. |
| ENF-k-3 | **The seccomp filter is the spike's deny list, the floor.** `confine` ports `spikes/ENF-radio`'s filter (no ptrace, mounts, namespace entry, bpf, modules, kexec, keyrings, perf, userfaultfd, cross-process memory, io_uring; `clone3` gets ENOSYS) and narrows `socket` and `socketpair` to the profile's families. BLE gets only `AF_UNIX`, for the system bus to BlueZ, so no IP, netlink, packet or raw Bluetooth socket. A per-stack allowlist from `strace -f -c` on hardware replaces the deny list later (spike README); this slice runs in CI only. | NET-2 Confined radio stacks, decision 6 | The allowlist becomes a per-profile list in `confine`, and the test adds a call outside it. |
| ENF-k-4 | **Each stack gets a fresh empty network and IPC namespace** (`CLONE_NEWNET`, `CLONE_NEWIPC`), so BLE sees only lo. Slice t's Thread and Matter profiles share one network namespace holding lo, `wpan0` and a dummy `infra0` (spike consequence 1); see ENF-t-1 and ENF-t-2. | NET-2 Confined radio stacks, D-231 | — |
| ENF-k-5 | **The launcher re-executes the enforcer's own binary to confine itself** (`confine.Trampoline`, first in main): Go cannot install a seccomp filter between fork and exec, so the child drops to the stack's user in the fork (`SysProcAttr.Credential`), then the re-executed binary refuses to go on as root or with supplementary groups, sets no-new-privileges, installs the filter on every thread, and marks every descriptor above fd 3 close-on-exec (`close_range` with `CLOSE_RANGE_CLOEXEC`, so nothing the enforcer inherited without close-on-exec, such as socket-activation fds, reaches the stack), and execs the stack with an empty environment. A failure exits 126 before the stack runs. The stack's user must be able to execute the enforcer's binary (slice m installs it world-executable under `/usr`). | decision 6 | — |
| ENF-k-6 | **The stack is untrusted, so its answers end the link on any fault.** A frame that does not decode strictly (length 1 to 4096 bytes, JSON with no unknown field and nothing after it), an answer to no outstanding request or for another device, a code off the closed list, or a notification for a device or characteristic the stack does not serve closes the link and fails every waiter at once; nothing it sent is used. An answer that arrives after its request timed out, naming that request's device, is dropped and the link stays (a slow device costs no restart); more than 64 requests left unanswered past their timeout ends the link. Restarting the stack is slice l's. Go's JSON decoder matches field names without case and keeps the last of duplicate keys; both ends are this package, so that admits no request the checks would refuse. | NET-2 Confined radio stacks | — |
| ENF-k-7 | **Answers are bounded at 512 bytes** (`MaxData`), above a reading or a GATT value. A stack handler that returns more is answered `CodeFailed`. | — | Raise `MaxData` with the frame bound if a stack needs more. |
| ENF-k-8 | **`Host.Do`, `Host.State` and `Host.Send` wait at most `Config.Timeout` (10 s) for the write and the answer together**, under the channel's lock (ENF-d-7); `Send` also stops when its caller's context ends, and checks that context only once it holds the link's write lock (`wmu`), so a send queued behind a slow write whose context ends while it waits writes nothing (`TestSendChecksContextUnderWriteLock`). The write has a deadline (`Conn.SetWriteDeadline`), so a stack that stops reading fails its link instead of holding a caller (`TestStackThatStopsReadingCannotWedgeHost`); a caller queued behind a blocked write waits at most one more timeout. They never wait for a device challenge's answer from the core. `Attach` closes a replaced link's connection without taking its `wmu`, so a write already under way on the old link is not ordered against a relock on the new one; that is safe only while a replaced stack's process has already exited before its new link is attached. | ENF-d-7 | A shorter timeout if the channel's lock hold matters in slice n's measurements. |
| ENF-k-9 | **The BLE process itself, BlueZ's D-Bus client, is the follow-up row ENF-k2.** This slice builds the host, the confinement, the interface and BLE's profile and declared ops; the brief's estimate (110k) did not fit a D-Bus client as well, so it is split rather than half-built. | budget rule (split before starting) | — |
| ENF-k-10 | **Slice r's per-device secret release is not here.** Releasing a device's secret only to its own stack's process is slice r's (`devsecret::TestReleasedOnlyToOwnDevice`); it can hand the secret down this interface or a second fd at start. | STO-4 | — |
| ENF-t-1 | **Thread's user namespace is created by the enforcer as root** (`confine.Thread`, `NetAdmin`: `CLONE_NEWUSER` in the fork, mapping only the stack's own uid and gid), never by the stack, so the enforcer image can set `unprivileged_userns_clone=0` (KERNEL-trim part b, #4094). In it ot-daemon holds `CAP_NET_ADMIN` and `CAP_NET_RAW` as ambient capabilities, which act only on its own network namespace (a tun `wpan0`, its addresses and routes, raw ICMPv6 for border routing); it is not uid 0 there and has no other capability. The launcher holds the stack before its exec, brings lo up and creates `infra0` (a dummy link, up and multicast) over route netlink inside the namespace, then releases it; ot-daemon refuses to start without its infrastructure link. | NET-2 Confined radio stacks, spike consequence 1 | The enforcer's kernel must keep `CONFIG_DUMMY` and `CONFIG_TUN` and `/dev/net/tun` mode 0666 (Debian's default); a trim that drops them fails `TestSrpReachesController`. |
| ENF-t-2 | **The Matter controller joins Thread's network namespace and nothing else of it** (`Spec.Net`): the launcher starts it from an OS thread moved into that namespace, as its own user, with no capability and a fresh IPC namespace; a profile with `NetAdmin` or links cannot join (`ErrJoin`). It reaches ot-daemon's SRP advertising proxy over mDNS on `infra0`, and Thread devices over `wpan0`. | NET-2 Confined radio stacks, spike consequence 1 | — |
| ENF-t-3 | **The deny list is one table, held to the kernel's.** `TestDenyListCoversKernel` reads the build host's `unistd_64.h` and fails if any namespace or mount entry point (by name: mount, the new mount API, `open_tree*`, `pivot_root`, `chroot`, `unshare`, `setns`) is missing or misnumbered; `open_tree_attr` (467), `statmount` and `listmount` joined. `TestFilterDeniesEachEntry` runs the filter program on a model of seccomp's interpreter and shows each entry is what refuses its call (a mutant without the line lets it through), which tells the filter apart from a kernel refusal for want of a capability (ENF-j delta L3, both findings). `TestFilterRefusesLive` shows the same live (#4233): a probe that is root of its own user, mount and network namespaces makes each namespace and mount call the stacks' probe claims, plus `umount2`, `chroot`, `fsconfig`, `fsmount`, `fspick`, `open_tree`, `move_mount` and `mount_setattr` (`pivot_root`, `open_tree_attr`, `statmount` and `listmount` have the interpreter model only); each succeeds with no filter and gets EPERM under the shipped one, and a synthetic filter without any one of those lines lets its calls through. A call the kernel refuses without the filter is reported `untested`, and fails the test. The stacks' own probe (`TestStacksConfined`) makes these calls in a single-threaded child and counts only EPERM as refused, since a threaded caller gets EINVAL from `unshare(CLONE_NEWUSER)` regardless of the filter. The CI runner's headers are older than the enforcer's kernel, so a call newer than them is caught when the image's headers are (slice m). | NET-2 Confined radio stacks | — |
