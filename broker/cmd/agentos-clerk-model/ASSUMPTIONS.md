# cmd/agentos-clerk-model assumptions

Built for MIG-4-untrusted-exit-b2b (#2780(b), briefs/MIG-4-untrusted-exit-b.md). Each row is a reading a reviewer may want to change.

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| MIG-4-untrusted-exit-b2b-1 | **Every refusal of the process comes before the key is read.** The main refuses root, then runs `procguard.Isolate` with agentosd's uid (refused as that peer, then non-dumpable), then checks `-dir` is this uid's own directory, closed to every other uid (`privfile.Check`); only then does it read descriptor 3 (`clerkkey.Read`, naming `model`). A refused start leaves the key in its pipe (`TestARefusedClerkLeavesItsKeyUnread`). | CLK-1 | none |
| MIG-4-untrusted-exit-b2b-2 | **The plan login lives in one sealed slot, and a slot that does not open refuses the start.** `-dir/plan-codex` holds `plan.Store`'s at-rest form, sealed under the sealer derived from this clerk's key and bound to the plan's name. It must be a plain file of this uid's alone, not a link, at most 64 KiB; a write past that is refused, so no form the next start would refuse is written (`privfile.WriteAtomic`). `plan.New` opens it at start, so a slot sealed under another key or for another plan refuses the start, unlike the mail clerk (MAIL-main-a-4); the owner removes it with `planremove`, which leaves the file empty (`TestThePlanLoginIsSealedInTheClerksOwnSlot`). | CLK-1, STO-2, CLK-7 | A second plan route gets a slot of its own, named for it. |
| MIG-4-untrusted-exit-b2b-3 | **This slice hosts the owner's plan sign-in only.** The process serves `ServePlanOwner` (`planbegin`, `planstate`, `planresume`, `planremove`) to agentosd's uid, and each sign-in's CLI runs through `run.SignInSock` on agentosd's `-signin-sock`, where the endpoint it serves in agentosd's route admits agentosd's uid, the sandbox host (clerk/run MIG-4-untrusted-exit-b1-1). A guest's model endpoint (`ServePlan` per guest), metering through the kernel's meter socket (`run.Meter`, MIG-4-run-n) and `ServeModel` are not served yet: each needs what only the guest host knows, the kernel plan a run is charged to, the route's price and pool, and the provider's context window and output limit (clerk/run MIG-4-plan-login-b6), and no model provider for `ServeModel` exists on main. Serving them with invented values would meter wrongly; serving them refusing would add sockets that do nothing. | PLN-5, CLK-7, LOG-7 | The guest host's slice (#2780(b3) or the row that restores `providerTask`) adds them, with `-meter-sock` and per-guest flags. |
| MIG-4-untrusted-exit-b2b-4 | **One uid, agentosd's, is every peer.** agentosd is the plan owner socket's caller (b3's `accountsock.Plan`), the sign-in socket's server and the sign-in machines' host, so `-agentosd-uid` names all three. It may be root, as agentosd is on the box; the clerk never is. | CLK-1 | If the pages' caller moves out of agentosd, the owner socket gets its own uid flag. |
| MIG-4-untrusted-exit-b2b-5 | **Its address policy is the mail clerk's, copied** (`netguard.go`, D-154 rule 4): the plan login's dials go only through the learned home-network resolver and the policy (DEV-2), with the system's roots, since the provider's hosts are public. | DEV-2 | none |
| MIG-4-untrusted-exit-b2b-6 | **A sign-in in flight at shutdown is ended by agentosd.** The process closes its owner socket and exits; agentosd destroys a sign-in machine when its caller's end goes (cmd/agentosd MIG-4-untrusted-exit-b1, `TestSignInStopDestroysTheMachine`), and the sign-in guest's placeholders die with this process's memory. | PLN-6 | none |
