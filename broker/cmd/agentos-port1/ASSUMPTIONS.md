# agentos-port1: assumptions

Built for KEY-9-reach-inbound-wiring (#5678, `briefs/KEY-9-reach-inbound-wiring.md`) against KRN-2, D-310, HW12-port1-set, CH-9 and HW-12. `agentos-port1` is the owner page's root step, moved out of `agentos-localui -admit-port1` with no change to what it does; it and `netguard/port1` are `root` lines of `tools/trusted_core.txt`. Each row is a reading a later change could overturn.

| # | Assumption | Basis | If it changes |
|---|---|---|---|
| PORT1-exec-1 | **`os/exec` with a fixed path and an empty environment is enough here; `childproc` is not needed.** The step runs as a systemd `ExecStartPre=+` command: systemd starts it with descriptors 0 to 2 only, so `nft` inherits no other descriptor; `/usr/sbin/nft` is an absolute path, so no `PATH` lookup; `cmd.Env` is an empty slice, so `nft` gets no variable at all (not even the manager's `DefaultEnvironment=`); the script goes on stdin, so no argument carries an interface name. `childproc` would add 361 lines and a `known` line (a `Trusted-core:` decision) for checks an empty environment already meets. The childproc gate (`childproc/gate_test.go`) lists this package as an exemption with that reason, as it does the enforcer's `nft` loader. | Brief step 2; ENF decision 4 (the enforcer's loader, same pattern) | If the step must pass `nft` a variable or a descriptor, or runs outside a systemd unit, it goes through `childproc` with a `known` line. |
| PORT1-update-1 | **No owner box carries a drop-in naming `agentos-localui -admit-port1`.** The drop-in is needed only on a board with two fixed Ethernet ports, where `port1.Port1` refuses; the first-release core boards have one, and no owner box ships before this image. A drop-in written before #5678 fails closed: `agentos-localui -admit-port1` exits non-zero with the line that replaces it, the unit does not start, and the page set stays empty. The test harness's drop-in (`broker/e2e/boxe2e`) names `agentos-port1`. | Brief, Lifecycle "Update" | If a two-port board ships with an owner drop-in, the image must rewrite it, or `agentos-localui` keeps a forwarding `-admit-port1` that execs `agentos-port1`. |
| PORT1-trust-1 | **Root runs only this binary's code.** Before #5678, root ran `agentos-localui`, so every `init` of the page binary's import graph ran as root too; `agentos-port1` links only `netguard/port1` and the standard library, and `tests/test_trusted_root_steps.py` fails when a unit's `+` command runs an agentOS binary that is not a trusted-core root. | KRN-2, D-310 | — |
