# Enforcer daemon: assumptions

Each row is a reading of the spec, or a property the code relies on, that a
reviewer may want to change (briefs/ENF.md slice l, ENF-l-a, #3670).

| # | Assumption | Spec basis | If it changes |
|---|---|---|---|
| ENF-l-1 | **One policy lock.** The page (`page.Config.Lock`), the book (`enrol.Config.Lock`), the channel (through `lockedPolicy`) and the clock's `Engine.Tick` share `Enforcer.mu`; the page and the book take it themselves, so `pagePolicy` takes none. `Book.Tick` runs without it held (ENF-c-8). | ENF-d-5, ENF-c-8 | A second engine caller wires through `lockedPolicy`. |
| ENF-l-2 | **The firewall follows the policy in force, never a request.** After a tightening (channel or page) the run loop is kicked; every tick also compares the hash of `Engine.Current()` with the last loaded and reloads (`nft.Reload` with the running table) only on a change. A refused load leaves the previous ruleset (nft's transaction) and is retried next tick. First boot loads the empty document's ruleset: default deny. | P4, P5, decision 4 | Byte-cap drops (`nft.Drops`) are ENF-l-b's, with the traffic counter. |
| ENF-l-3 | **State is files in one directory the daemon alone can read.** The directory must be owned by the running user with no group or other bits and not be a symlink; stores are replaced atomically (temp file, fsync, rename, fsync of the directory) and journals are appended with fsync. "The enforcer's sealed store" (ENF-a-7) is this directory on the image's encrypted, verity-backed data partition (slice m); no TPM sealing here. The daemon refuses to run as root. | STO-4, NET-2 Hardening | Slice m names the partition and the unit's user and capabilities (CAP_NET_ADMIN, CAP_NET_BIND_SERVICE). |
| ENF-l-4 | **The page is rebuilt, not mutated.** When the passkey in force changes (enrolment, recovery applied, factory reset) or the leaf certificate renews, a new `page.Server` is built and the listeners move to it; the old page already refuses taps from the moment the book's passkey changed (`live`), so the gap refuses rather than accepts. Challenges and anti-forgery tokens drawn by the old page do not carry over. | ENF-c-8, NET-4 | — |
| ENF-l-5 | **The core trip here is the minimal cut DECOY-d builds on.** A frame outside the format or a burst trips it (`channel.Cut`), it is saved before the alerts and survives a restart, a repeat trip writes nothing (#4606), and only the page's passkey resume lifts it (`page.Channel`, ActResume), which also resolves the channel-paused alert and the core's trip. A trip raises `ChannelPaused` and `Trip` (device `core`; the light goes red, ENF-h-a4). The firewall's cut of the core's segment, the "core reflashed" stage, `heads.Store.Trip` and the modem and edge plugs are DECOY-d's (#3765). | KRN-12 Response, NET-2 Channel, ENF-d-4 | DECOY-d replaces `cut` with its own and keeps `cut.json`'s meaning. |
| ENF-l-6 | **The core's channel sub-key is a pinned file.** `core.pub` (base64) is written when the core is set up beside the enforcer; with none, the daemon runs no channel and no head store, and alerts reach only the page, log and light. The enforcer's own channel key is made on first start (`channel.key`, mode 0600) and printed with `-channel-pub` for the kernel to pin. Pairing both keys through the page is not built. | DEV-2, KEY-7 | A pairing step on the enforcer's page writes `core.pub`. |
| ENF-l-7 | **The core counts as up while it spoke within `Silence`, two summary intervals.** Every channel log line but a failed hello's is the authenticated core's and refreshes it, on the rate clock. SPEC KRN-12 Silence names a heartbeat "at a fixed interval" that the format definition does not yet set; one beat per `wire.SummaryInterval` is assumed. A cut core whose lines pass `KindPaused`'s bucket goes unlogged and can read as silent. | KRN-12 Silence, NET-2 | The interval moves into `wire` and both ends read it. |
| ENF-l-8 | **The channel listener is the per-source limit.** Only `core_allow` addresses get a TLS handshake (others are closed unanswered), at most `MaxCoreConns` connections are open at once, a handshake has 10 s, and TLS 1.3 runs under a certificate made for each run that nothing trusts: the hellos bound to the exporter authenticate both ends. | ENF-d-4, ENF-d-w1 | Slice o's client must dial TLS 1.3 without verifying the certificate and send the hello. |
| ENF-l-9 | **The rate clock is CLOCK_BOOTTIME** (`bootTime`, x/sys/unix), which never steps back and counts through suspend; a failed read returns the last reading. The wall clock is for the log and the policy's times only. | #4507, ENF-d-10 | — |
| ENF-l-10 | **Until ENF-l-b, the box's other pieces fail closed.** The access point refuses (`unwiredNetwork`), so enrolment enrols nothing and the setup network stays; every radio command and state read is refused (`noRadio`); the light's colour goes to the log until its driver lands (#4305); the page has no action, sealed-secret or heard-names inputs, so it refuses those links. | P1, P5, ENF-c-7 | ENF-l-b wires `ap/push`, `radio`, `devsecret`, `action`, `mdns` and the rest. |
