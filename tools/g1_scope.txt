# G1 list (G1-freeze, #1687): the paths a PR may touch until G1-e2e (#1688) passes in QEMU.
# Read by tools/g1_scope.py; the g1-freeze workflow uses the base commit's copy.
#
#   freeze on|off       the single switch. Lift the freeze with a PR that changes it to
#                       `off` and cites a #1688 QEMU run whose e2e DONE line reads
#                       fail=0 xfail=0 blocked=0 (guest-task and phone control included).
#   since TIME          when the freeze began (UTC, 2026-10-14T19:55:00Z form). A PR opened
#                       earlier passes (Mark 2026-10-14: "let current PRs finish"); the
#                       time comes from the pull_request event, which the author cannot set.
#                       The push that merges #1687 sets it to that push's time.
#   exempt-pr N         PR N passes: an amend for work already under way that the time rule
#                       misses (a split or rebuild of a row in flight when the freeze began).
#   allow PATH          a PR may touch PATH: a trailing "/" means everything below it,
#                       otherwise the one file.
#   frozen-import DIR/  a broker package G1 binaries import but the list freezes anyway
#                       (Mark's Tight choice: learning code serves A11/A12, not G1). The
#                       drift test in tests/test_g1_scope.py accepts these as imports.
#
# The broker entries are every package the G1 binaries import (`go list -deps`, see
# G1_BINARIES in tests/test_g1_scope.py): the image's six binaries (image/build.sh), the
# guest bridge, the seller tool (D-105), the checker (CH-4) and clock-boot and hostdisk
# (HW-8). The drift test fails when a G1 binary starts importing a package not named here.
#
# One model route (D-104; Mark 2026-10-14 19:35Z, "ChatGPT plan" on Decisions card
# cmsg_01R63S2yrPkq32thy8WQCuvDFt5XhL8peUFCaddWFQZ4YR): G1's model-backed task runs on the
# owner's ChatGPT plan through the Codex provider worker, broker-held (D-061, D-114, D-117).
# Wiring it is G1 work: the plan-login chain #807 -> #1015 -> #1014 -> #1314 -> #1264, enabled
# by #809. So guest/codex/ and broker/provagent/ (new in #1314) are listed. The API-key
# adapters' own files (broker/route/openai*, broker/route/anthropic*) freeze, so broker/route/
# is listed file by file; the code they share with the guest's chat path stays listed. The
# Grok, Muse and Claude plan routes (#1378-#1380) freeze with their rows.
