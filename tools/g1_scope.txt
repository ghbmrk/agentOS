# G1 list (G1-freeze, #1687): the paths a PR may touch until G1-e2e (#1688) passes in QEMU.
# Read by tools/g1_scope.py; the g1-freeze workflow uses the base commit's copy.
#
#   freeze on|off       the single switch. Lift the freeze with a PR that changes it to
#                       `off` and cites the passing #1688 QEMU run.
#   allow PATH          a PR may touch PATH: a trailing "/" means everything below it,
#                       otherwise the one file.
#   frozen-import DIR/  a broker package G1 binaries import but the list freezes anyway
#                       (Mark's Tight choice: learning code serves A11/A12, not G1). The
#                       drift test in tests/test_g1_scope.py accepts these as imports.
#
# The broker entries are every package the G1 binaries import (`go list -deps`, see
# G1_BINARIES in tests/test_g1_scope.py): the image's six binaries (image/build.sh), the
# guest bridge, the seller tool (D-105), the checker (CH-4) and clock-boot and hostdisk
# (HW-8). The drift test fails when a G1 binary starts importing a package not named here.
#
# One model route (D-104, Mark 2026-10-14 18:12Z): G1's model-backed task uses the
# Anthropic API-key route through agentos-egress (broker/route/anthropic.go), the first
# provider in the image's egress rule. Other routes freeze with their rows: the worker-held
# Codex CLI (guest/codex/), the OpenAI adapter's own files (broker/route/openai*), and the
# plan routes (#1377-#1380, no code yet). Code the adapters share (broker/egress,
# broker/route/route.go, broker/meter, cmd/agentos-egress) stays listed, so a path list
# cannot hold the OpenAI half of it; the frozen rows' labels do.
