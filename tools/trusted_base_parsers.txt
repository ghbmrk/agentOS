# Parser registry for tools/trusted_base.py (SPEC KRN-2, #2849).
#
#   parser <pattern> -- <what untrusted bytes it decodes>
#   inert  <pattern> -- <why it decodes none>
#
# A parser is a package that turns bytes a party outside the trusted processes can write
# (a guest, a network peer, a device, the local UI or a phone, the modem bridge, owner text,
# an update mirror, a backup) into structure. Fixed-alphabet codecs (base64, hex,
# encoding/binary) are not parsers. A pattern is an import path; `/...` also matches its
# subpackages; the longest path wins, and an exact path beats `/...` on the same one. Every linked package outside the standard
# library must match a line here; a standard-library package counts only if a parser line
# names it. An own package whose inputs are uncertain is classed parser: an overcount shows,
# an undercount hides. Turning a parser line inert needs a `Trusted-base: registry --` reason.
