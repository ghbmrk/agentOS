# The trusted core and its shrink-only budget (KRN-2cap, #2935; change 1 of the 2026-10-23
# ideal-backwards review, approved by Mark). Read by tools/trusted_base.py on every PR. This is
# the one list of D-154's keeper domain (D-157): the kernel's verdict and key state, the kernel
# process that holds the log key and head, the sealed store, the unlock step and the clerks.
#
#   root <dir>                  a package of the core: a directory under broker/
#   allow <path>                one package the core may link with no known line and whose
#                               lines do not count: only packages of golang.org/x/crypto and
#                               golang.org/x/sys. The standard library is always allowed.
#   known <path> -- <reason>    a package outside the roots, the standard library and the allow
#                               lines that the core links today. Shrink only: adding one, adding
#                               an allow line, dropping a root, or growing the core's lines over
#                               the merge base needs a `Trusted-core: <decision ID>` line in the
#                               PR body naming Mark's decision. A known line the core no longer
#                               links fails until it is deleted.
