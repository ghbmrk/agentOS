# W7-A: connect verified owner outcomes to measurable learning (design)

The managed tree already reaches private agents on main. Reuse
`TestW4AdoptedTreeReachesTheAgent`, `TestW4TreeReachesOnlyPrivateMachines`,
`TestBridgeMirrorsTheManagedTree`, `TestBridgeKeepsItsTreeWhenTheBrokerDoesNotSendOne`
and `TestBridgeRunsSkillThroughBroker`. A stale W7 board label is not evidence
that these paths should be rewritten. Verify assembled-image behavior first.

## Owner feedback boundary

Only verified, authenticated owner approval/edit/NO/UNDO outcomes feed attention
Observe and harvest. Agent-generated evidence, a peer's claim, an expired approval
or an undelivered notification is not owner judgment. Preserve OP-7's separation
of permission, observed effect success and goal quality. Use the existing channel
provenance and Queued.Late rules for implicit auto-reply acceptance; retain its
per-day caps, half weight and explicit-anchor requirement.

UserContent configuration must be explicit and fail closed. Reuse the channel's
short-ID allocator, require LocalUI for page suggestions, and route declines back
to the optimizer. Suggestions stay drafts; creating or widening a grant uses the
existing high-tier owner flow. Keep current ten-approval and twenty-unedited-reply /
10%-edit thresholds until a reviewed experiment supports changing them. Synthetic
success alone cannot lower a threshold or create a pre-allowance.

## Assembled repeated-task scenario

Capture an owner-accepted goal through the real channel, harvest its case and
maintain goal-separated development and held-out sets. Propose through the change
pipeline, qualify against held-out/security suites, and verify that the skill
reaches only a private guest. Run effects through ordinary effect_request checks.
Force an assumption failure and observe model fallback. UNDO restores the prior
procedure where applicable. Forget removes/rebuilds the adoption and mirror as
designed; pending forget cannot report success early. Private-derived skills stay
unshared, and held-out expected outputs never reach a builder.

Proposed named cases:

- TestW7VerifiedFeedbackOnly: unverified approval, expired request and agent text
  create no trusted outcome; authenticated owner edit/NO/UNDO reaches the right source.
- TestW7SuggestionDoesNotGrant: repeated approvals produce a draft suggestion;
  LocalUI off refuses it and acceptance still needs the high-tier grant flow.
- TestW7AdoptionReachesPrivateGuest: pipeline -> managed tree -> actual guest ->
  effect_request -> verified result, using existing W4 components.
- TestW7FallbackUndoForget: force an assumption failure, rollback, then forget
  during evaluation/adoption; no leaked held-out case or retained private derivative.
- TestW7InvisibleReplyHasNoImplicitGood: failed/late owner notification cannot be
  harvested as positive visibility, and existing caps/anchors still hold.

These are acceptance specifications, not passing-test claims. Authority-sensitive
feedback and adoption wiring needs the strongest independent reviewer.

## Benefit experiment before allocation or model policy changes

Compare AgentOS, unmodified OpenClaw and direct provider CLI on the same host,
accounts/routes and task corpus. Include qualified computer-use task classes
under the SUB-1 proposal when no equivalent structured capability exists. Reset
external state and independent workspaces; counterbalance arm order. Separate
first-use from repeat-use. Freeze workload/hash, versions, warm state, concurrency,
repeats, gain target, regression margins and rollback triggers before qualification.

Measure owner-active minutes per accepted task, accepted tasks, end-to-end latency,
necessary/avoidable approvals, usage in its original units, failures and fallback.
Start timing at task initiation: compile.Measure's first-effect-to-last-outcome
span omits earlier planning. Include rework/rejected attempts in effort. H6's
`tools/measure_trials.py` collects these records without launching model/account
calls and refuses incomplete comparisons; collector tests are not product benefit.

A gain must hold on unseen goals with unchanged authority/security checks. Report
sample sizes and variability. A favorable median or a smaller context packet alone
cannot justify a model downgrade, new memory/RAG framework, or changed threshold.
Keep the owner's deferred LOOP-7 active-testing work deferred.

Runtime implementation is pending external review. Depend on the W5-D1 durability
contract where digest visibility is required; never assume the current in-memory
modem queue provides durable delivery.
