# POT-P8: Qualify one local leverage pipeline

**Owner:** primary, unclaimed. **Class:** release for adopted CAP-13/A10 qualification; broader pipelines wait for evidence. **Tier:** A for routing/egress/adoption wiring.
**Requirements:** CAP-9/13, CHG-1/2, OP-8, ARC-2/7, REV-5; D-051 and D-039.
**Needs:** SR3-7 canonical reserved requests, POT-P1 baseline, POT-P3/P6b outcome evidence, the existing accelerator/resource lease path.

Reserve capacity and accelerator discovery are not a running inference service. Choose one recurring, deterministically checkable task class and freeze the acceptance/cost/latency targets first. Write a bounded implementation brief for a worker-hosted inference service and its class-specific pipeline; no model runs in the broker.

Compare the main route alone with (a) extractive preparation then main route and (b) cheap-first, deterministic check and authorized escalation. A pass receives only data in the original routed call; no hidden recall or expanded retrieval. Extractive reduction preserves source spans, and cannot silently invent or omit required fields. Treat all model output as data. Hosted compute uses the required TLS/key pin, identity requalification and private-data opt-in. All branches, retries and escalation count against the task reservation and total measured cost.

Acceptance: held-out owner work preserves quality and security while meeting the predeclared useful gain; adversarial omissions/modified spans fail the check; escalation without budget/grant is refused; local service failure, version change and quota loss fail over under existing policy. Bound memory/leases so foreground work stays responsive. No default-on or breadth expansion until the chosen class passes. Tests first, Linux/floor-host measurements, strongest-model L3/threat check and separate Security/lens review. Initial checkpoint: 25k tokens per service/pipeline slice.
