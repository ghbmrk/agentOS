# P2-2: Owner Card and local web UI

Board section: Phase 2: real hardware (cloud parts).

Owner Card and local web UI: card generation and printable card with QR codes, paper grid and recovery sheets (ONB-7; [assumptions](../broker/card/ASSUMPTIONS.md)); local UI with setup steps 5-6, sign-in, local unlock that clears challenge mode, STOP and RESUME, CH-9 guards and captive portal (CH-7–9, ONB-1, ONB-3–8; [assumptions](../broker/localui/ASSUMPTIONS.md)). The access point driver is a seam (`localui.AccessPoint` plus generated hostapd, dnsmasq and nftables configs) for P2-1 on hardware. Wiring: the modem loop calls `Server.OfferText` until setup has an owner; `Hooks.Finish`'s caller starts the owner channel, calls `SetOwner`, and sends `AllSetText`
