## Requirements

CH-15 / OP-1: acquisition refuses any symbolic ancestor before creating the lock;
subsequent named-parent checks use the same nofollow resolution and latch recovery
on refusal, even if a symlink would lead back to the held final parent inode.
OP-8: clean absolute ledger paths must be at most 4095 bytes, with at most 64
parent components and no embedded NUL; reject outside these bounds before opening.
Keep only one traversal descriptor at a time, plus the next opened component.
Reuse Linux openat/O_DIRECTORY/O_NOFOLLOW and D50 descriptor-relative ledger I/O.
The path-only os.Open/syscall.Open final-no-follow call cannot enforce this rule
for intermediate components. Ordinary Store/FileStore remain unchanged.

Tests first: reproduce symlink acquisition and live symlink-to-same-inode acceptance
on D50, then implement the smallest bounded walk. Test exact resource boundaries,
fixed recovery/no lock creation, actual strict Gate/session debt reopen and failed
lookup cleanup. Scoped race/vet/trace plus pinned fresh bundle; independent review
and CI results reported only when observed. Builder Codex (GPT-6), one package.
