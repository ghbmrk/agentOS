# H8: Deterministic split entropy for change cascade fixtures

Board section: Harness and operating model.

**Source draft:** [#273](https://github.com/ghbmrk/agentOS/pull/273) (Codex), +40, conflicts only in BOARD.md.

Change cascade tests draw pipeline split entropy from the live source, so a fixture's split can differ run to run and the cascade tests are order- and luck-dependent. Give the test environment a fixed, test-only entropy source in `env_fixture_test.go` and use it from `env_test.go`.

**Requirements:** CHG-1 (existing coverage made deterministic; the draft carries `REQ: CHG-1`).

**Scope:** `broker/change/env_test.go`, `broker/change/env_fixture_test.go`. Test files only; production entropy stays untouched, and no test hook is exported from non-test code.

**Acceptance:** run `go test ./broker/change -count=200 -shuffle=on` before (show any variance) and after (stable); race detector on Linux.
