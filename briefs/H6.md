# H6: A10 trial collector

Acceptance A10 compares matched trial outcomes; today nothing collects them. Add a collector that pairs trials by task, reports outcomes per pair, and keeps each resource unit (tokens, wall time, owner prompts) in its own column instead of summing unlike units.

**Scope:** the three files above. Stdlib Python only; no network, no credentials, synthetic fixtures.

**Acceptance:** unit tests for pairing, missing-pair handling and unit separation; `python3 tools/doclint.py` clean.
