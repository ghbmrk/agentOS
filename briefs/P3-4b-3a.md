# P3-4b-3a: LOOP-7 child-process runner and fuzz source in agentosd

Board section: Phase 3: the agentic loops. Part of P3-4b (briefs/P3-4b.md); SPEC LOOP-7, LOOP-9, LOOP-1, ARC-2.

**Goal:** the fuzz loop runs on the box. #523 merged `broker/loop7` (fuzz targets, the socket probe hook, `Journaled`) and #515 merged `broker/probecmd`, but agentosd links neither: `learn.go` builds the scheduler with `Sources: {sleepSource, l.guard}`, the image carries no fuzz binary, and nothing calls `Report` from Loop 7. This package builds one reviewed way for agentosd to start child processes, hardens it (minimal environment, process-group kill), puts the fuzz binaries in the image, and wires `loop7.Source` in front of the guard. The socket probe stays off (`Probe` nil) until P3-4b-3f picks the probe machine. Canary rounds and corpus replay on the box stay in P3-4b-4c, which uses this package's runner.

**Requirement IDs:** LOOP-7 (off-the-shelf fuzzing runs in spare capacity), LOOP-9 (a crash goes through `Report`), LOOP-1 (only in spare capacity), ARC-2 (agentosd cannot reach inference; the child-process path is reviewed). Tests carry `REQ: LOOP-7, LOOP-9` (add ARC-2 on the import, `escapeOK` and environment tests, and LOOP-1 on the cadence test).

**Sources:** BOARD rows P3-4b-3a and P3-4b-4c; `reviews/potency/2026-10-09-pr523.md` point 1 (build the binaries, pick the probe machine, pass `Report`, state disk and build time against HW-4); #523 L3 (release: production wiring); `reviews/security/2026-10-09-pr515.md` findings 1 (timeout kills the process group), 2 (minimal environment, owed check) and 4 (tier A for `loops`, `probecmd`, `corpus`, `loop7`); LATER P3-4b-3 l1 (environment) and l3 (loop7 tier A); BOARD P3-4b-4b's owed check; `broker/probecmd/command.go` doc (wiring needs an `escapeOK` review); `broker/loops/ASSUMPTIONS.md` S28.

## Requirements (each with a test)
1. **One reviewed exec path (ARC-2).** agentosd starts child processes only through one package. The builder picks one of two designs, records it in `broker/cmd/agentosd/ASSUMPTIONS.md`, and gets Security sign-off. (A, recommended) An `escapeOK` entry for `os/exec` in `broker/daemon/inference_test.go`, limited to `loop7` and `probecmd`, whose runners execute only binaries listed in the signed release (`/usr/lib/agentos/fuzz/…`), never a path from config or state. (B) A runner outside the daemon (a separate unit started by systemd) that agentosd triggers over a socket. B keeps `os/exec` out of agentosd but adds a process and a protocol. Tests: the import graph test still passes and names the new entry; a binary path outside the release list is refused before exec.
2. **Children get a minimal environment** (#515 Security f2; LATER l1). `loop7.command` (today `append(os.Environ(), "GOFLAGS=")`) and `probecmd.CommandProbe` set an explicit allow-listed `Env` (`PATH`, `HOME` set to a scratch directory, `TMPDIR`, `GOCACHE` set off or to scratch, `GOFLAGS=`), never the daemon's. Owed check: a test in `broker/daemon/inference_test.go`, next to ARC-2's, walks non-test broker code with `go/ast` and fails when an `exec.Cmd` is built without `Env` assigned in the same function. Tests: a child run with a canary variable set in the parent does not see it; the AST check fails on a planted fixture and passes on the tree. On merge, delete LATER P3-4b-3 l1.
3. **A timeout kills the whole process group** (#515 Security 1). Both runners start children with `SysProcAttr{Setpgid: true}` and set `cmd.Cancel` to kill `-pid`; `WaitDelay` bounds the wait for pipes. Test: a child that backgrounds a sleeping grandchild is killed with it on timeout (the grandchild's PID is gone within `WaitDelay`).
4. **Fuzz binaries in the image** (Potency 1). `image/build.sh` builds each fuzz target with `go test -c -o $STAGE/usr/lib/agentos/fuzz/<pkg>.test` (19 `func Fuzz` today, one binary per package), plus a manifest listing target names and binaries that requirement 5 reads and requirement 1 checks. Seed corpora ship read-only beside them; new crash inputs go under the state dir (`/var/lib/agentos/loop7`), never into the image. The PR states the added image size and build time, and checks them against the HW-4 floor (4 cores, 8 GB). Test: `tests/test_image.py` asserts the manifest lists every `func Fuzz` in `broker/` (a new target without a binary fails CI).
5. **agentosd wires the fuzz source** (Potency 1, LOOP-9). `learn.go` wraps the guard in `loop7.Source{Inner: guard, Report: guard, Targets: <manifest>, FuzzTime: 30s, Every: 1h, CacheDir: <state dir>, Probe: nil}` and puts it in `Sources` in place of `l.guard`. Loop 2's passive checks still run every round; fuzzing runs only in spare capacity, as loop7 already does. Tests: with a fake target that crashes, a round reports one `fuzz` finding through the guard; the guard's passive pass still runs in the same round; a preempted round leaves no finding.
6. **The cadence stays within the owner text** (LOOP-1; feeds P3-4b-3c). A test computes the recheck interval from the wired config, (targets + 1) × `Every`, and fails above 12 h, so P3-4b-3c's "every few hours" stays true. If the target count grows past that, the builder lowers `Every` or groups targets, not the wording.
7. **Tier A for the loop packages** (#515 Security 4; BOARD P3-4b-4b's owed check; LATER l3). Add `loops`, `loop7`, `probecmd` and `corpus` to `TIER_A_BROKER` in `tools/risk_tier.py`, with pins in `tests/test_risk_tier.py`. On merge, delete LATER P3-4b-3 l3 and mark the owed check done on P3-4b-4b's row.
