# P2-1: Device image

Board section: Phase 2: real hardware, cloud parts first.

Device image: mkosi build of Debian 13 with `/usr` on dm-verity in A/B slots, shim -> signed systemd-boot -> signed kernel, counted boot entry blessed only after a health check, release manifest binding the `/usr` root hash to its boot entry, build-time refusal of per-install state and socket files (V15), root growing to fill the drive, broker + runsc + OpenClaw guest inside, pinned inputs with a two-runner rebuild check, Secure Boot QEMU boot in CI (HW-1, HW-5, UPD-1 boot counting and health gate, UPD-1a) ([assumptions](image/ASSUMPTIONS.md)). Done here from carry-forwards: W1's `launch.json` at `/usr/lib/agentos/guest/launch.json`; P2-9's `systemd-timesyncd` enabled. Hand-offs: P2-3 adds the modem udev rule and the `agentos-modem` user, with ModemManager kept off the modem; P2-4b K1 adds state mounted `noexec,nosuid,nodev`, no unauthenticated rescue or emergency shell, and stops `/etc` drop-ins on the unverified root from overriding `agentosd.service`, and seals to PCR 9 or a signed PCR 11 policy (C1); P2-4 adds `agentos-egress`'s unit and encrypts owner state before any drive ships (C2); P2-2 writes `/etc/agentos` 0700 and `agentosd.env` 0600 with validated values (C4); P4-2 builds the clean-room image and W3-builder-image the builder image, each registered with `-image`; the update package writes sysupdate transfers and TUF metadata over `release.json`; S1 boots only main-built images (C3)
