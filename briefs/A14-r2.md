# A14-r2: runsc gets --network=none on every launch path, checked at runsc (A14)

Board row: issue #1132. Source: #674 Security and L3 reviews ([comment 6091547146](https://github.com/ghbmrk/agentOS/pull/674#issuecomment-6091547146), [comment 6091556930](https://github.com/ghbmrk/agentOS/pull/674#issuecomment-6091556930)). Class: release. Tier: see the PR (`tools/risk_tier.py`). Builder: strongest model (tier A). Usage estimate: 60k tokens, checkpoint at 45k.

**Why (facts, verified at main 9338b37).** `TestAGuestCannotDial` checks `r.argv(r.launchArgs(l, image)...)`, the helpers, not what `Start`, `Restore` and `launch` hand runsc. `argv` puts the pinned global flags first, so a caller global flag placed after them (`--network=host` ahead of the subcommand) is runsc's last value and wins, and a launch path that builds its own command never meets the test. Surviving mutations on #674 showed both.

## Requirement (from SPEC.md)

- **A14** (SPEC.md:673): a machine reaches no address it is not allowed; invariant: the guest has no network.

Package IDs:
- **A14-r2-1** `Start` and `Restore` start runsc only with argv runsc takes as `--network=none`: no network flag after the subcommand, no `--allow-flag-override`, and `none` as the last global value, on every runsc run they cause.
- **A14-r2-2** `cmd` (through `argv`) pins `--network=none` and the other runtime global flags after any global flag its caller passes, just before the subcommand, so no caller argument widens the guest's network.

## Acceptance tests

**Acceptance tests:**
- A14-r2-2: `broker/vm/gvisor/nonet_test.go::TestRunscStartsEveryGuestWithoutANetwork`: a recording fake runsc captures the argv `startConsole` and `cmd` pass for run, restore, and caller args with `--network=host` or `-network=sandbox` ahead of the subcommand. Runs unprivileged.
- A14-r2-1: `broker/vm/gvisor/nonet_test.go::TestStartAndRestorePassRunscNoNetwork`: `Start` and `Restore`, overlay mount included, against the recording runsc; every captured run or restore argv must pass. Root only (the CI integration job runs `./vm/...` as root).
- Mutations that must fail at least one of these: drop `--network=none` from argv; `startConsole` or `Start` runs runsc past `cmd` with `--network=host`; `launchArgs` adds `--network=host` after `run`; argv restored to base-first order.

## Design

`argv` scans the caller's leading `-`-prefixed args (global flags, `-name=value` form) and inserts the pinned flags after them. runsc takes a flag's last value (Go `flag`), so the pin wins. Record the runsc parsing assumptions in `broker/vm/gvisor/ASSUMPTIONS.md`.

## Scope

`broker/vm/gvisor/gvisor.go`, `broker/vm/gvisor/nonet_test.go`, `broker/vm/gvisor/ASSUMPTIONS.md` (new), this brief.

## Out of scope

`childproc` (no error-carrying constructor), the bundle's network namespace (already checked by `TestAGuestCannotDial`), runsc flag allow-listing beyond the network.

## Done

CI green; both acceptance tests pass in CI (the root one in the integration job); the mutations above each fail a test, reported in the PR.
