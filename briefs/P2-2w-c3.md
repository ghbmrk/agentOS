## Boundary with P2-2w c4

c3 owns the helper and agentosd's `JoinNetwork` wiring, end to end: the page's `AgentosdSetup.JoinNetwork`, a `localapi` setup op, `localsrv.Setup` serving it, and agentosd calling the helper.

c4 keeps every other setup hook: `Networks` (the list in range), box number, host info, texts, host trust, providers, and real progress (including `Online`). Because the helper may answer `saved` (L8.4), c4's `Online` step is where the owner learns that the box never got online; c4's brief must say so. c4 also gives `cmd/agentos-localui` its `AgentosdSetup`. Until c4 lands, the network step works through `InProcess` and in tests, as pairing does today (L28).

## What to build

Build exactly the note's L8 conditions 1-7. Fixed points for the builder:

- **D-Bus client.** Reuse a mature, vendored client, preferably `github.com/godbus/dbus/v5`: BSD-2, no dependencies of its own. The PR says why if it chooses otherwise. Running `nmcli` with the PSK on its command line is not allowed (L8.5).
- **Connection.** Found only by the fixed UUID in L8.4 (`GetConnectionByUuid`), created with `AddConnection2`, changed with `Update2` on its own path. The settings are exactly L8.4's list.
- **Join outcome.** The helper reports one of L8.4's six codes from property reads after autoconnect, within a fixed wait of at most 40 seconds. It holds no `network-control` and takes nothing down. On a single radio with the access point up and no station device, the answer is `saved` (L8, "What the radio does"). agentosd maps `joined` and `saved` to success for the page, and every other code to the page's existing error.
- **Page wording.** The page's wording and its one "Could not join that Wi-Fi" error stay as they are.

## Acceptance tests

1. A peer whose uid is not agentosd's is refused before its request is read. Oversized, malformed or extra-field requests are refused with fixed codes.
2. Bounds are checked before any NetworkManager call. Test each SSID and PSK edge: 0, 1, 32 and 33 bytes; 7, 8, 63 and 64 characters; 64 hex vs 64 non-hex; non-printable characters. A refused request answers `refused` and makes zero D-Bus calls on the fake.
3. The first join looks up the fixed UUID with `GetConnectionByUuid` and creates the connection with `AddConnection2`; a second join changes it with `Update2` on that path. The fake records no `ListConnections` call, and no `GetSettings`, `GetSecrets`, `ClearSecrets`, `Update`, `Update2` or `Delete` on any other path. It records no device method and no activate or deactivate call. The settings sent are exactly L8.4's list, compared key by key, with the request's SSID and PSK.
4. One fake-state test per answer code: `joined` (an active connection with the UUID reaches `ACTIVATED`), `not_joined` (it appears, then reaches `DEACTIVATED` or goes away), `saved` (none appears within the wait), `busy` (a second join while one runs), `failed` (the fake returns a D-Bus error on the write), and `refused` (test 2). One test runs the fixed wait out with a fake clock. agentosd's mapping is tested: `joined` and `saved` succeed for the page; every other code gives the page's existing error.
5. Once setup is closed, the join op is refused at `localsrv.Setup` and the helper is never called. The 7th try in a minute is refused.
6. A synthetic canary PSK appears in no log line, error, journal entry, setup record or agentosd state written during the tests, and only in the request to the fake.
7. A test parses the unit file and the polkit rule:
   - unit: the dedicated `User=`, an empty `CapabilityBoundingSet=`, no `AmbientCapabilities=`, `NoNewPrivileges=yes`, `RestrictAddressFamilies=AF_UNIX`, `IPAddressDeny=any`, `ProtectSystem=strict`, `ProtectHome=yes`, exactly one writable path (the socket directory), and no `EnvironmentFile=`;
   - polkit rule: the only `polkit.Result.YES` is under `subject.user ==` the helper's user and `action.id ==` `org.freedesktop.NetworkManager.settings.modify.system`; every other path returns `polkit.Result.NOT_HANDLED`. The test runs the rule's function under a small JS evaluator or a fixed-text check, whichever the builder can vendor at least cost; the PR says which.
8. CH-9: the diff touches none of localui's listener, source-subnet check or `NftRules` (a test or a CI path check), and L5's existing tests still pass.

Run tests with `-race` on Linux. A mutation that drops the peer check or the bounds check must fail a test.

## Out of scope

- Listing networks in range.
- Ethernet detection.
- Changing the home Wi-Fi after setup (LATER P2-2w c3 f1).
- Creating a station device beside the access point (one radio in concurrent mode, or a second adapter): P2-1, row P2-2w c3 r4. c3 answers `saved` without it.
- Whether NetworkManager's store is encrypted at rest (L8.6): row P2-2w c3 r3.
- A busconfig policy narrowing the helper's D-Bus calls: row P2-2w c3 r1, unless the builder folds it in (one file and one parse test).
- SAE-only and non-broadcast home networks: LATER P2-2w c3 f2, f3.
