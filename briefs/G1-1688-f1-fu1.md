# G1-1688-f1-fu1: MissedLog names agentosd's own caller, not owner's wrapper frames

Board section: Harness and operating model. Work item: #2349. Follow-up of PR #2345 (lost-send logging, #2170 item 3; review comment 6250400958, finding 1). **Tier A** (`broker/modemlink`, `broker/owner`).

**Why.** `callers()` in `broker/modemlink` records at most 3 frames, and all are inside `owner`: a real run logged `via owner.watchedLine.Send via owner.(*Channel).sendReserved via owner.(*Channel).NotifyNow`. Failure path: #1291 can tell only which owner entry point lost a send, not which agentosd sender called it.

**Requirements:**
- G1-F1: `callers()` skips owner's own wrapper frames (`owner.watchedLine.*`, `owner.(*Channel).send*` and the entry points they wrap), as it already skips `(*Link).` frames, so the three frames reach agentosd's sender.
- G1-F2: the 3-frame cap and the 16-pc bound stay.

**Acceptance tests (REQ: G1-F1, G1-F2):**
- `broker/modemlink/callers_test.go::TestMissedLogNamesTheCallerBeyondOwnerWrappers`: a send through a real `owner.Channel` from a local func; the local func is named (mutant: skip nothing).
- `::TestCallersKeepCapsAfterSkipping` (F2).

**Out of scope.** The log format; `broker/e2e/boxe2e` unless its NOTE expectations change.

**Scope:** `broker/modemlink` (`callers()` and its test), this brief.

**Usage estimate:** 30k tokens.
