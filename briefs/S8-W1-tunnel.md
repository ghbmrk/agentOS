# S8-W1-tunnel: CONNECT-only tunnel for a worker-held provider CLI

Board section: Release rows carried from LATER.md (2026-10-10). Source: work item #1014 (from the S8-W1a inventory, #543; `docs/security/provider-worker-isolation.md` row "Provider inference tunnel"). Tier A (egress, vm, image). On G1's plan-login path (Mark chose "Plan login", 2026-10-13): fourth in the chain #808 → #807 → #1015 → this → CAP-11-plan → #1264.

**Why.** In worker-held mode the CLI holds its own login and talks TLS end to end to its provider, so the broker cannot inject or read the traffic; it can only decide where the bytes go. At current main the egress proxy answers every `CONNECT` with a journaled denial (`broker/egress/proxy.go`, ASSUMPTIONS E12) and a worker has no network and no broker socket (`broker/workers` package doc), so a worker-held CLI has no way out at all. The image also carries no provider CLI.

**Requirements:** CRED-5 worker-held W4 (CONNECT host on the declared list, resolved by the broker, ClientHello SNI equal to that host; the CLI's provider-side fetch tools off by managed policy; tool subprocesses have no network) and W3 (inference-scoped login only), CAP-11 (CLI auto-update and telemetry off; versions change only through image updates), A14 ("a provider agent in a worker cannot reach any host but its provider's declared model endpoints, and a tunnel whose SNI differs from its CONNECT host is refused"), DEV-2 and E12 (no home-network or non-global address, also by rebinding), OP-8 (the run is metered even though the stream is opaque: run count and wall clock, CRED-5 W7).

**Change.**
- **Tunnel endpoint.** A per-worker listener the broker serves only for a worker whose spec names a worker-held provider, reached through a unix socket bind-mounted into that worker. It accepts `CONNECT host:443` and nothing else: any other method, a port other than 443, an IP literal, or a host off the provider declaration's tunnel list is refused and journaled (host only).
- **Broker resolution.** The broker resolves the host itself through the box's `netguard.Policy` dialer (E12); the worker's own DNS is never used (it has none). A name that resolves to a non-global or home-prefix address is refused, on every lookup.
- **SNI binding.** The broker reads the first TLS record from the client, parses the ClientHello, and requires its SNI to equal the CONNECT host exactly (case-folded, no trailing dot); missing SNI, ECH outer names that differ, a record that is not a ClientHello, or a ClientHello split past a size cap all close the tunnel. Only then is the upstream dialed and the bytes spliced. No TLS termination, no reading of later records.
- **Metering.** Each tunnel is journaled as one run segment (provider ID, worker, bytes each way, duration), charged to the creator's reservation under OP-8; per-run byte and wall-clock caps close it.
- **Inside the worker.** A pinned forwarder in the provider image exposes the socket as `HTTPS_PROXY` on loopback inside the CLI process's network namespace only. Tool subprocesses run in #807's sandbox with their own empty network namespace, so they see neither loopback nor the socket.
- **Image.** A provider worker image (built by `image/build.sh` beside the base worker image) adds the official, unmodified Claude Code CLI at a pinned version and checksum, and image-fixed managed settings: auto-update and telemetry off, `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` (S8 measured 6 direct tunnels without it), WebFetch, WebSearch, remote sessions and MCP denied. The builder records each setting's source in `image/ASSUMPTIONS.md` against the pinned version.
- **Declaration.** The tunnel list and the auth host come from the provider declaration (CAP-11), data not code. For Claude: the inference host(s) the pinned CLI uses with `CLAUDE_CODE_OAUTH_TOKEN`; the builder measures them against a stub with `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1` and records them.

**Tests first.** CONNECT to a declared host with matching SNI splices to a stub upstream; mismatched SNI, missing SNI, a non-ClientHello first record, an oversized split ClientHello, a declared host that rebinds to a private address, an IP literal, port 80, a host off the list and a plain `GET` are each refused and journaled without payload. A worker without a worker-held provider gets no socket. From a tool subprocess in the worker (stub CLI, #807's sandbox), loopback, the socket path and any address are unreachable. The image build fails when the CLI checksum or a managed setting is missing. A stub CLI run with the image's settings opens no tunnel to an undeclared host.

**Threats Security must check.** SNI/Host split (allowed SNI, then a foreign Host header inside TLS: W4 says qualification checks the provider edge refuses it; this package records the S8-live probe that does). Domain fronting via an allowed CDN name. Rebinding between check and dial (dial the address the policy approved, not the name again). ClientHello parsing as attack surface (bound sizes, fuzz target in `image/fuzz-targets.json`). An allowed host used as an exfiltration channel under an attacker's own key (W4's reason tools have no network: prove the socket is unreachable from tools). The forwarder or its env visible in `/proc` to tools. Upstream TLS downgrade is out of the broker's reach by design; say so in ASSUMPTIONS.

**Needs:** #807 S8-W1 (tool sandbox and managed policy; the tunnel must not ship before tools are cut off from loopback). #1015 S8-W1-volume (the worker spec field naming the provider). Can build against stubs in parallel with #1015 if the spec field is agreed first.

**Out of scope.** The login volume (#1015), the route and its guest tool (CAP-11-plan), page sign-in (#1264), Codex or any broker-held route, live checks against real provider edges (S8-live).

**Scope:** `broker/egress/tunnel.go` (new), `broker/egress/proxy.go` (CONNECT dispatch only), `broker/egress/*_test.go`, `broker/egress/ASSUMPTIONS.md`, `broker/vm/gvisor/gvisor.go` (socket mount), `broker/vm/worker.go`, `broker/vm/*_test.go`, `broker/cmd/agentosd/main.go` (wiring), `image/build.sh`, `image/mkosi/*` (provider worker image), `image/fuzz-targets.json`, `image/ASSUMPTIONS.md`, this brief.

**Usage estimate:** 150k tokens. Split if past the checkpoint without green: (a) broker tunnel with SNI binding, (b) provider worker image and in-worker forwarder. Builder model: Opus-class (tier A).
