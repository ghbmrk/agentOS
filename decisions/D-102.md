# D-102: Controller and helper system

Date: 2026-10-12. Source: Mark, "Install on mini PC vs drive" thread, confirmed 2026-10-12 ("helper app on gaming pcs + Mac, workstations as is, controller as is"; "workstation = dedicated computer; helper app = dual use computer").

## Decision

1. The controller is a headless mini PC running agentOS from its internal SSD, and holds everything private. The phone is the only UI.
2. One signed image serves controller install, recovery and workstations. Acquisition is a signed GitHub flasher or a third-party preloaded mini PC with a claim sticker (no agentOS-operated service, 2026-10-04).
3. Helpers hold nothing private at rest: code plus hash-verified public weights (signed manifest on GitHub pins each hash).
4. Two helper forms: a workstation (dedicated computer, installed image, private content allowed) and a helper app on dual-use Windows or Mac machines (cleared content only). CAP-13 is unchanged. No stick helpers, no reboot-into-helper.
5. The broker routes by content class: private (default) goes only to the controller and installed workstations; cleared goes anywhere. Mixing taints: private plus cleared is private.
6. Network: port 1 to the router, port 2 a private segment for workstations, helpers accept the controller only (mTLS).
7. The box generates every Owner Card at first boot (changes HW-1, REC-4).

## Relation to earlier decisions

The 2026-10-05 external-drive design is narrowed, not erased: D-044 (HW-8, the drive-based path) stays active for a moved SSD, and the trusted-host and unknown-host rules (CRED-8, HW-5a) remain the security basis when a drive moves. Rows D-100 and D-101 are reserved for PR #1028's renumbering; renumber in merge order on collision.
