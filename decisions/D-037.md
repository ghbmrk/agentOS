# D-037 (2026-10-05)

Deletion reach into agent work (CAP-3, recalltool W10): deleting a record removes it from recall at once. An agent lineage that has done no work since it first read the record is rolled back to before the read without asking. One that has done work is rolled back only after the owner approves a text naming the restore point and the work so far ("forget a mail you deleted from agent, back to 08:12 Oct 5; 2 actions stay done").

**Source:** Mark, project chat ("Ask, but only if work after that point")
