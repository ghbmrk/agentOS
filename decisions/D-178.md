# D-178: The enforcer is standard, and setup runs on its Wi-Fi only

Date 2026-10-26. Source: Mark in Decisions 8, "Make enforcer standard - require home control - there should be a single trending-to-ideal system without excessive modularity" (cmsg_01R91wiieBzMSvPKFsAJVvuKN7riPYu8qewFPKztYhxBcm, 12:11:33Z), then option 0, "Enforcer's Wi-Fi only", on the card cmsg_01R91wiieBzMSvPKFsAJVvuK8BWGz91qwW1kgQSyh2DGfm (tap cmsg_01R91wiieBzMSvPKFsAJVvuKSqjuWpv22cqx1nQT7QZBbn, 14:32:12Z). It applies D-173: nothing ships in a weaker form that the final design would replace.

**Decision.** Every installation has a core, an edge, and an enforcer with its access point, so home control is part of every installation and the spec keeps no "without home control" branch (HW-14, HW-15, HW-16, CH-7, CH-9, NET-2, NET-4, A19). The core and the edge never turn Wi-Fi on: their image runs no access point, Wi-Fi client, captive portal or passthrough (NET-2, CLK-1's exceptions, ONB-5). Setup runs on the enforcer's networks from step one (§12.1): the claim sticker names the enforcer's setup network, which opens only the enforcer's enrolment page; that enrolment enrols the owner's passkey, installs both certificates and replaces the setup network with the Owner network, whose password only the enforcer holds; the core's claim and setup pages then open on the Owner network (HW-10, CH-9). On the preloaded path the seller preloads the enforcer and its access point too; on the download path the same flasher writes the enforcer's signed image and shows or prints its setup-network QR, so neither path needs a seller (Mark, option B "flasher does both" on the card cmsg_01R91wiieBzMSvPKFsAJVvuKVEi28umgiop7zuH16mJkVg, tap cmsg_01R91wiieBzMSvPKFsAJVvuKAcvZcxuyTEF6Qaosw5SBF5, 2026-10-26 17:19:51Z). The home-network step leaves setup, because the core's uplink is its cable to the enforcer (HW-12, ONB-3).

**Gates.** G1 stays proven (D-128) on the core's own Wi-Fi. A1's setup path is re-run through the enforcer's networks in G6, and G6 (A16, A18 and A19's home-control clauses) moves before the first release.

**Code this deletes.** The core's access point (`broker/cmd/agentos-ap`, `broker/localui`'s hostapd and AP loader, `broker/apnet`), its Wi-Fi join (`broker/netjoin`, `broker/cmd/agentos-netjoin`), captive passthrough, and their image units and CI steps. Queued as its own row behind this SPEC change and the `cmd/agentosd` serial chain (D-111).

**Unchanged.** D-105's residual moves to the setup network's password on the sticker. The Owner network stays WPA3-SAE only (D-081).
