# D-233: Enforcer response to a breach-decoy trip (NET-2, HW-2, REC-5)

Date 2026-10-29. Source: Mark in the Decisions thread (cmsg_01R63S2yrPkq32thy8WQCuvDPEYNqp2ZagYe5Gw87Ue4BS): "Cut on trip" (card cmsg_01R63S2yrPkq32thy8WQCuvD5HQmLG3y2dfrsZFRn7KF4J, 2026-10-28 23:52:54Z), "Enforcer cuts it" (card cmsg_01R63S2yrPkq32thy8WQCuvD75upAi9Pnha7wgkzpVEbSC, 2026-10-29 00:45:23Z), and "Yep do that but also some process to resolve whatever pathway to breach in first place - light can be notification (which light?) as would have to be home to sort it out anyway; it not responding remotely is enough. Modem can always be added later" (cmsg_01R63S2yrPkq32thy8WQCuvDDQomXL2fJLVFvCfW3sTyPQ, 2026-10-29 00:48:58Z). Follows D-232.

**Decision.**
- **Cut on trip.** On a KRN-12 trip the enforcer cuts the box the trip came from. A core or edge trip drops that box's internet, while the channel and the owner page stay. A Devices trip isolates that device. Only a passkey-signed loosening lifts a cut. Silence stays an alarm only.
- **Modem power.** A core trip also switches off the plug that powers the owner-line modem (HW-2: a powered hub, a USB power blocker on the core-to-hub cable, and a safety-list Thread plug), so a compromised core can neither reach out over the carrier nor text a false "all fine".
- **Alert path.** The light, one Thread bulb only the enforcer drives, shows red for every unresolved alert. The box no longer answering remotely is the notice. An own LTE line is a later option, not built now.
- **Recovery (REC-5).** After a core trip, a compromised restore is offered to the newest head the enforcer or a backup kept, in REC-2's restricted mode, with fresh decoy wallets. Before the passkey lifts the cut, the visit names the pathway (the boundary, plus the input, route or package that reached the decoy) and closes it: it narrows or removes that key, device, route or package, and files a fix or drill case.
