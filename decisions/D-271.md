# D-271: Root unit commands are pinned whole (#4493, KRN-2)

Date 2026-11-02. Source: Security reject on PR #4559 (comment 6573272343, fourth round), then the L3 and Security fix-lists on this row's first head (comments 6574948903, 6574962392): a program allow-list that does not parse arguments lets `agentosd`, `agentos-kernel`, `agentos-unlock` and `agentos-link` (run as root only as arguments to `with-uids` or `sh -c`) fall out of the root-side check, and listing `sh` would pass `sh -c '…'` and `nft -f /tmp/x`. Standing rule: structure first.

**Decision.** The root-side lint in `broker/kernel/privfile` (`TestRootSidePathOpsGoThroughPrivfile`, #4493) stops modelling argv text and pins instead:

1. Every root unit command is pinned whole, word for word, with its unit and a reason, in a units-only file. The list for udev, modprobe, sysctl and tmpfiles stays separate and unchanged. No argument is modelled; any change to a root command is a reviewed edit of its pin.
2. Each whole-word broker binary path in a pin joins the root side. A pinned script's reason line names the broker binaries it starts.
3. No pinned absolute word may be reached through a shipped link or a `pathAliases` alias.
4. Units under `broker/` are read too.
5. A shell runs as root only as a pinned whole command, its script word for word. No shell is ever listed as a program, and the program list for udev, modprobe, sysctl and tmpfiles never names one. (Moving the `sh -c` lines into script files was rejected: `mkosi.finalize` pins `KERNEL_REBOOT`, the exact `sh -c` text of agentos-keeper-kernel's `ExecStopPost`, and checks Exec values for `REBOOT_WORDS`, so a script file would hide `systemd-run` from that guard.)

**Why.** A deny-list over argument spellings has false passes by construction. A pin fails closed: a new spelling, wrapper or argument is simply a different command that is not pinned. It also keeps the check small, and no lens gets worse.

**Review.** The reviewer checks that a root unit command is admitted only by an exact pin, that every broker binary a pin starts (directly or through a pinned script's reason line) is counted, that a link or alias on a pinned absolute word is refused, and that a shell appears only inside a whole-command pin and never as a listed program.

**Auto-decided** by the coordinator (no lens worse); no Mark card.
