# D-261: Trusted-core growth for #4314 (REV-CHK-save-kernel)

Date 2026-10-31. Source: approved design briefs/REV-CHK.md §REV-CHK-save (#3903), issue #4190. Standing rule: D-159.

**Decision.** PR #4314 (issue #4190, tier A) may grow the trusted core by +11 lines (`tools/trusted_base.py measure`, 40739 to 40750 against main at cf01198), in `broker/kernel/proc`. All of the growth is test-only write-stop seams: the fields `FileContent.stop`, `FileKeys.stop` and `backups.stop`, and a `stop` parameter on `initCounterAnchor` and `restoreItems`, each passed to `privfile.WriteAtomic`. Production passes nil, so no production behaviour changes.

**Why in the core.** The tests stop each save of the kernel process after every write step. The write calls are inside `broker/kernel/proc`, so a stop has to reach them through those fields and parameters; a test file cannot reach inside them, and a package-level hook would add a mutable global to the core instead.

**Review.** The reviewer re-measures on the PR head and checks that every added core line is a stop seam passed to `WriteAtomic` and that production passes nil; growth beyond that is a finding, not a waiver.
