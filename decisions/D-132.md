Date 2026-10-19. Source: Mark, Questions thread, 2026-10-19 12:39:04Z (cmsg_01R63S2yrPkq32thy8WQCuvD9656QAZsVzGV4BeBa9NSNP): "Yes", answering "File all three?".

**Decision.** Three additions to the guest role (ARC-3, builds on D-131):
1. The guest delegates by intent and data label and proposes a route as a hint, ranking the label-allowed routes by its own model knowledge (the hint grants no authority). The broker filters by data label, holds per-route hard facts and measured acceptance per task class (CAP-9), and overrides the hint on measured evidence; overrides are journaled and LOOP-4 turns them into routing rules. Amended by Mark's "Yes" at 12:43:26Z (cmsg_01R63S2yrPkq32thy8WQCuvDHkDkGsf41pkK2bAWe51nQr).
2. Plan usage per accepted task is a LOOP-3 return measure, and the guest's instructions are an adoptable context rule under CHG-6 (held-out suite gate).
3. Pool-aware guest switch: when the Codex plan pool falls below the reserve (RES-5), the next task runs under the Grok or Muse guest, through a standing owner rule beyond ARC-3's per-switch tier-3 intent.

4. Muse requires Contributor mode off (Mark "Yes", 12:49:22Z, cmsg_01R63S2yrPkq32thy8WQCuvDCCENG4PA91Kpi8JKSywhDi): the Muse guest and Muse CAP-11 workers are qualified and run only with it off; the sign-in check refuses a run while it is on; pool sizing uses the reduced non-Contributor allowance.

**Readings (not in Mark's words, for his typed line).** The rule is a pre-allowance: set with CH-10's high-risk proof, turned off by the pause/revoke command for pre-allowances (CH-11, ADP-9), with the skills-change notice given once when it is set; it applies only to guests the owner has connected and that are qualified; it returns when the pool resets; each switch is journaled. The route hint ranks only routes CAP-9 admits, and with no measured evidence CAP-9's default order decides across tiers while the hint orders within a tier. "Guest instructions fit CHG-6's context-rule class" is an interpretation of that class, bounded by an explicit extension of its definition (instructions change only how the guest uses services and data it already has).
