# D-135: Guest qualification order

Recommendation: **Yes**.)"; Mark said no to it.

**Decision.** The CLI guests of D-131 qualify in the order Codex, then Muse, then Grok. It is a sequence, not a gate: a guest that passes qualification is listed without waiting for an earlier one. Refines ARC-3's "qualify one at a time" (D-131), which named no order; the default-guest rule is unchanged.

**Reading (not in Mark's words, for his typed line).** "codex muse grok for guest" is read as both the qualification order and the preference order. Where a later ARC-3 rule needs a tie-break, such as the pool-switch target or the default for a setup with only a Muse or only a Grok plan, Muse comes before Grok. The spec does not yet apply it to those rules; they stay [Open].
