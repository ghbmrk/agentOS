# D-316: SPEC text moved out still counts

Date 2026-11-10. Source: Mark, "Yes they count" (cmsg_01R91wiieBzMSvPKFsAJVvuKCozEXjcLLLcewtcKaLJtyM, 2026-11-10 01:52:26Z), answering whether tables and acceptance-case files holding text moved out of SPEC.md count toward the D-310 spec-words ceiling. Context: project file `answers/2026-11-10-spec-shortened.md`.

**Decision.**
1. Words moved from SPEC.md into a table or acceptance-case file still count toward the 65,725 spec-words ceiling (D-310) and the D-152 shrink rule. Moving text saves nothing; only stating a rule once, deleting a case its rule already implies, and deleting history and examples save words.
2. The PR that first moves SPEC text into a file outside SPEC.md adds that file to the counted set in the same PR: the `spec` set in `tools/word_budget.py` and `spec_words` in `tools/trusted_base.py` (gate files, Security accept per D-137). Until then the tools count SPEC.md alone, which today holds all such text, so no tool change is needed now.
