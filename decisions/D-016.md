# D-016 (2026-10-05)

First third-party Go module in the broker: `rsc.io/qr` v0.2.0 (QR encoding for the Owner Card and setup page). Accepted against "near-zero dependencies" because it is encode-only, BSD-licensed, has no dependencies of its own, and is vendored (`broker/vendor`), so builds never reach a module proxy (DEP-1); its one URL literal is a PNG metadata string recorded as inert in `assurance/dependencies.json`

**Source:** P2-2 review (L3 + lens gate, PR #32)
