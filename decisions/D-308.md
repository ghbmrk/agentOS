# D-308: Prune unused guest files

**Date:** 2026-11-03. **Status:** active. **Serves:** PLN-5, EVL-5, HLD-3.

**Decision.** Guests are untrusted, and known-vulnerable code does not ride along in a guest image unused. A guest's image build MAY delete installed files the guest runtime never loads. The pruned image is the one qualified (HLD-3), so qualification is the evidence that nothing needed was removed. Pruning is not a fork: no file the runtime loads changes, and no interface of PLN-5 changes.

**Scan.** The known-vulnerability scan (EVL-5, "an image dependency") reads the guest image as shipped, not only the lockfile's registry tarballs. A copy that the build deletes stops being reported, and an accepted-vulnerability record that covered only that copy retires in the same PR.

**First use.** #4436: OpenClaw's Control UI assets (`dist/control-ui/`), unused since #4419 turned the Control UI off, carry DOMPurify, KaTeX, mermaid and lodash-es copies with known advisories.

**Fallback.** If OpenClaw stays too vulnerable after pruning, Codex can become the default guest (PLN-5's guest options).
