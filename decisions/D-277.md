# D-277: Trusted-core growth for #4720 (KRN-proc-print)

Date 2026-11-02. Source: issue #4719 (KRN-proc-print, tier A). Standing rule: D-159. Basis: DECOY-b-8's pointer-to-pointer rule and KRN-1's fail-closed rule, the same approval as the earlier release rows (D-267, D-268, D-270, D-273, D-274).

**Decision.** PR #4720 (issue #4719) may grow the trusted core by +19 lines (`tools/trusted_base.py`, 41238 to 41257, as measured by the builder), in `broker/kernel`, with no new linked packages. The added lines are:
- non-printing key types, so that `proc.Kernel` and the keys it holds print no key value: the `proc.Kernel` head and link keys, the CounterAnchor signing key and the held recovery card;
- one guard in `Log.Append` that refuses a plan ID the log would rewrite or that is invalid UTF-8, so no log entry holds text the log rewrites. It covers Submit, Cancel, Undo, ReadPool and Reserve.

**Review.** The reviewer re-measures against the base at merge (the baseline moves as other core rows land, for example D-273 and D-274) and checks that every added core line is one of the two kinds above; growth beyond them is a finding, not a waiver. The guard fails closed: a refused plan ID is an error, never a silent rewrite.
