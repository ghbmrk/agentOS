# D-105: G1 installs and pairs by the preloaded path

Date 2026-10-12. Source: Mark, card choice in the project's Decisions thread, 2026-10-12 13:46:35Z (project message cmsg_01R63S2yrPkq32thy8WQCuvD4KBoEJ7HENUApLRq4EzWtT, option 0, "Preloaded").

**Question.** How should the first M6 Ultra be installed and paired with the owner's phone? Staging (D-104) moved both the signed flasher (FLASH-1) and the seller's preloaded-image self-check (CTRL-uki) after G1, and those are the only two routes HW-10 offers for pairing a phone with a new controller.

**Decision.** G1's install and pairing route is SPEC §8.1's seller's preloaded path. The project acts as the seller for this one box only: it prepares the M6 Ultra as a seller would and ships it with a claim sticker, and the sticker's one-time claim code (HW-10, merged in #1080, CTRL-claim-wire) pairs the owner's phone. This uses merged code and needs no new pairing design.

**Unchanged.** Selling to others, the signed flasher and the rest of A17 stay after G1, as D-104 set. The design (SPEC HW-10, §8.1, D-102) is unchanged and this decision adds no SPEC text.

**Options not taken.**
- Flasher first: build the signed flasher now. Rejected because it pulls the flasher ahead of G1.
- Manual stick: a new pairing design. Rejected as the slowest and riskiest.
