# D-311: Rebuild the owner layer on proof rungs; sessions open on the page

Date 2026-11-03. Source: Mark 2026-11-03 18:01:38Z, "1 rebuild now" (cmsg_01R91wiieBzMSvPKFsAJVvuKHddeNtfmZeZBd9rhK9Z5XG), answering the Decisions 8 card "Rebuild the owner layer now, deleting the code generator once passkeys pass?" (cmsg_01R91wiieBzMSvPKFsAJVvuKB6FH9kVDfYhXwYGFY6pGRj), option "Yes, rebuild now". Design: the rearchitecture note of 2026-11-01 (§2.1, §3.1, §5), held to D-307.

**Decision.** The owner layer is rebuilt on the kernel, not ported:
1. **One proof ladder.** CH-3 defines five rungs once, ordered by what an attacker must hold: P0 the number's claim, P1 a texted one-time code returned, P2 the handset (reserved until S2), P3 a passkey tap or, while CH-4 stands, a code-generator code on the owner page at home, P4 a hardware key. A rung is one more caveat kind on keys (KEY-2), not a new mechanism (D-307's three). CH-3's rows stay as the floor and test cases (D-307) and name rungs in place of repeated proof wording; no row's required proof changes.
2. **Sessions open only on the page** (CH-14). The inline unlock goes: no session unlock by a texted code-generator code or grid cell, no `RUN` or `RUN 1 3`, no held-text readback by text. Held task messages wait for the page, which shows each in full and runs what the owner taps. This replaces the CH-14 parts of D-080 (the hold stays) and D-087.
3. **The code generator and grid go once QUAL-page-ca passes** (WebAuthn on the page under `.internal` on the iPhone). If it fails, CH-4 stays. Until then, rows that build code-generator plumbing (MIG-4-exit-c2-unit, the code half of MIG-4-exit-c3) are held, not built.

**Cost, as the card stated.** Until S2, or for good if S2 fails, a session opens only at home; the owner lengthens N there before a trip.

**Rows.** The plan in the project files (`plans/2026-11-03-owner-layer-rebuild.md`) orders seven: this spec diff, the phone wording, surfaces as declarations, the rung caveat in `broker/kernel/key`, the page session in `broker/owner`, surface declarations in code, and the generator's deletion.
