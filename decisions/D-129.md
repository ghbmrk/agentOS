# D-129: Quiet hours and urgent classes

Date 2026-10-17. Source: Mark, Decisions 6 thread 2026-10-17 19:50:57Z ("Accept all", cmsg_01R91wiieBzMSvPKFsAJVvuKR4uan8CS199UZr1LtSwnbR) on the W5-Dc-r14 card, which put the six provisional choices of briefs/W5-Dc-r1.md (SG-r1-1 to SG-r1-6) to him as explained in cmsg_01R91wiieBzMSvPKFsAJVvuKQ6Ss3EwUAh6iMtY8Au5Umo.

**Decision.** CH-15 states the pacing rules W5-Dc-r1 built provisionally, reconciled with D-097 and D-127:
1. **No default quiet hours (SG-r1-1).** None until the owner sets them; the onboarding defaults line says so.
2. **Urgent classes (SG-r1-2).** A closed set of four. `security` is always urgent. `approval` and `agent` are owner-switchable. `update` is never urgent. Urgent texts go at once, past quiet hours and the hourly limit, and still count toward the hour.
3. **The hold (SG-r1-3).** Held pushes wait on the box, saved, at most 32; past that the oldest is dropped and the next text counts the drops. On release they go oldest first, combined into as few texts as CH-12 allows, each counting as one push. Agent text is never combined with another text.
4. **Replies (SG-r1-4).** A broker reply to an owner message is conversation: it skips pacing and quiet hours and does not count. This extends D-127's open-chat rule to control-word replies, STATUS and requested code texts.
5. **Setting words (SG-r1-5).** `QUIET <from>-<to>`, `QUIET OFF`, `TEXTS <n>` (1 to 20) and `URGENT APPROVAL|AGENT ON|OFF` join CH-11's closed set, take effect only in an unlocked session (CH-3), and are confirmed in fixed wording. They are written in CH-15, not CH-11, to stay clear of DIG-RM-spec's CH-11 edit.
6. **Digest (SG-r1-6).** Dropped: D-097 removed the digest.

**Reconciliation, for Mark to confirm.** D-097's CH-15 made "approvals that block work" and deadline or work-holding questions urgent by default. The card said only that approval and agent can be switched to urgent and named no default. This decision keeps D-097's default: `approval` (those approvals and questions) is urgent unless switched off, and `agent` is urgent only if switched on. The merged pacer (`broker/owner/pacer.go`, O21) defaults `approval` to not urgent and maps agent questions to `agent`; that divergence is a release finding. If Mark prefers the card's reading (approval not urgent by default), the CH-15 class sentence changes and the code stands.
