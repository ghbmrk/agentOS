# D-131: Four guest options

Date 2026-10-19. Source: Mark, Questions thread, 2026-10-19 12:15:27Z (cmsg_01R63S2yrPkq32thy8WQCuvDJokSX4bBb42N24w3iZCASV): "Did this already - the four are the 3 frontier plan ones (codex, muse, groq) that have the right cli situation + openclaw".

**Decision.** agentOS has four guest options (ARC-3): OpenClaw, the default, and the official CLIs of Codex (ChatGPT plan), Grok (xAI) and Muse (Meta). "Groq" in Mark's line is read as Grok (xAI), the plan route in CRED-5 and #1378; Muse is Meta's, as in D-117 and #1379.

**Why** (Mark, 2026-10-19 12:18:55Z, cmsg_01R63S2yrPkq32thy8WQCuvDFF6wgNfyQbB7S7rK1TXwSE): OpenClaw on default hardware has no capable local model; the goal is a frontier plan orchestrating local resources for more efficiency on finite, expensive usage. Each CLI guest is accepted only if it hands reduce, extract and check passes to local models and compute hosts through broker tools (CAP-13) and the plan usage saved is measured.

**Also (Mark, 2026-10-19 12:22:01Z, cmsg_01R63S2yrPkq32thy8WQCuvD9p95vszSRNhkYFbqkVCzv3).** Broker tools should make delegation effective; guest instructions are refined to do it without bloating per-request tokens; the guest, as main orchestrator, uses the smartest model without prohibitive latency by default and maximum capability on deeper tasks. **Open:** how maximum capability is reached (proposed: a CAP-11 worker at top model and effort); Mark has not chosen.

**Shape (proposed by the coordinator and adopted in SPEC; interpretive points flagged for review).**
1. Each CLI guest runs only through ARC-6's interface; model calls go to the broker's provider endpoint with a placeholder credential.
2. Custody is broker-held only (D-117 sets all three to broker-held). A guest machine is an agent machine, so a worker-held plan (Claude Code opt-in, D-114) is not a guest option. This is the one point not in Mark's words.
3. Each CLI guest is qualified per version through §11 and LOOP-11 and appears in the owner's list only once qualified. How owner messages enter its inbound API is a declaration and qualification item, not a blocker.

Antigravity and Gemini CLI stay excluded (#1409 amendment, Mark 2026-10-14 00:29Z). Builds on guest/codex (a CAP-11 worker today) and #1377 to #1379. The rest of #1409 (broker-held state, cross-provider check) is not part of this decision.
