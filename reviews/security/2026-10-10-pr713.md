**Threat check.** Assets: main's integrity (only reviewed or bot-generated changes land), the workflow token, the meaning of the required checks. Adversaries: a holder of repo write access (Mark, an agent session, a parallel team, any of them prompt-injected); PR text read by `metrics.py`; a race between runs.

| Path | At this head |
|---|---|

CI is no guard here: the branch supplies its own `ci.yml`, the `pull_request`-only TRACE.md and risk-tier steps are skipped on dispatch runs, and any writer can dispatch a green same-named run on the head. Not a new GitHub capability (the main ruleset requires no reviews; a writer can already merge), but it bypasses the review rule (D-091, OPERATING §7) without anyone deciding to merge. Procedural only: release finding f1 |

If it does, trace regenerates an identical file, `gh pr close` on the merged branch fails into `|| true`, and the run exits |
| Racing runs | each workflow has a fixed concurrency group without cancel; `commit` checks out current main, so a later run never proposes an older tree. Freshness only (L3 later) |
