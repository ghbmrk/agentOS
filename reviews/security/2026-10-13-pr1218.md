## What changes for an attacker
`agentos-localui` used to serve a fixed not-ready page. It now runs real setup through `AgentosdSetup` over agentosd's `localui.sock`. The setup steps that are actually live are progress, the home-Wi-Fi join (now also a rejoin form on the number step while `never_online` holds) and the pairing code display. The number step and texting are inert until c4c (#1220): `BoxNumber` is `""` and `OfferText` is not wired. Host trust, providers, API keys and device-code sign-in all still return `errNotServed`, and `host()` saves nothing when `TrustHost` errs.

| Path | Stop | How |
|---|---|---|
| An unauthenticated party reaches setup | structural | It has to join the AP first. Before the confirm that is WPA3 with the sticker's PSK (HostapdConf still calls `Validate`, and the AP switch is #1185), then the card's. CH-9's listener, subnet check and `NftRules` are untouched, and L5's tests pass. |
| Another local uid drives setup ops | structural, unchanged | `setupMode.run` sets `PeerUID`/`PeerGID` = the page's uid, with `MaxConns 8` and a 30 s idle timeout. |
| Setup ops after finish | structural | `localsrv.Setup.open` gates every op, including progress (mutation dropping it is killed). `AlreadySetUp` treats no answer as closed (mutation `return false` is killed). `awaitSocket` keeps a page that starts early from closing setup for its whole life (no-wait mutation is killed). |
| Join flooding or overwriting from the page | structural, unchanged | `JoinsPerMinute = 6` is counted before the shape check, `MaxSSID`/`MinPassword`/`MaxPassword` are checked in agentosd, and `Valid` runs in the helper. The typed SSID input's `maxlength` is client-only, but the server bounds the same value. Rejoining from the number step adds no capability: before pairing, the POST was already accepted at any step, and after pairing `mayLocked` limits it to the paired phone. |
| Wi-Fi PSK in logs, argv, env or responses | structural, unchanged | The PSK travels only in the POST body, then `localapi.Join` (redacting `String`/`GoString`), then D-Bus. The new `Seen` hook gets only the `netjoin.Code`, and only on a nil error. `uplink.go` and `awaitSocket` log nothing and return fixed errors. The form never echoes the password or SSID back. |
| Claim code or card material | n/a | The diff does not touch them. The page config still carries no `SetupSecret`, `Card` or AP password (pinned by `TestThePageRunsSetupThroughAgentosd`). |
| `New` dropping `Validate` when hooks are set | accepted | The page never reads `SSID`/`Password`. `ValidateServe` keeps the CH-9 checks (interface, private /16-/30 address), and a mutation dropping it is killed. |
| ARC-2 | structural | `agentos-localui` imports `localapi` types only. `TestThePageLinksNoneOfAgentosd` passes unchanged. `uplink.go` only reads `/proc/net/*`: no exec and no new imports beyond `localapi`/`netjoin`. |
| core.txt and the childproc/egress gates | unchanged | Neither file is in the diff. The `./core`, `./childproc` and `./sockets` tests pass. |
| Page restart after pairing (MemStore) | accepted (L18/L28) | A restart starts setup over, and the newest-seed rule plus the card hold on finish cover it. This becomes reachable only once c4c wires texts. |
