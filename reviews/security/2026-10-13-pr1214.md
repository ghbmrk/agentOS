## Threat model

The assets are:
- the home Wi-Fi PSK (CRED-1)
- NetworkManager's system connections, including the access point's
- the childproc gate, the ARC-2 import guards and the core list

The adversaries are:
- a compromised page process (L25)
- another local uid
- a compromised agentosd
- a holder of the access-point password
- a compromised helper
- a later change that widens what this PR exempts, or that gets reviewed at a lighter tier than it should

## Findings

- **B1 (blocker, tier A; CRED-1, OPERATING §3).** `broker/netjoin` is a new broker package. It carries the PSK, holds the peer-uid binding (`server.go:23`), and holds the L8.5 bounds (`join.go:82`) and the L8.4 settings list. `tools/risk_tier.py:59` (`TIER_A_BROKER`) leaves it out, so it rates **B**.
  - OPERATING §3 requires such a package to join `TIER_A_BROKER` "in the same PR that creates it". OPERATING §2 says to pick blocker when unsure between blocker and release.
  - Failure path: a delta confined to `broker/netjoin/`, such as dropping `PeerUID` or `Valid`, gets a tier-B pass with no Security re-sign. That includes fix pushes on this PR after sign-off.
  - Fix in this PR:
    1. Add `netjoin` to `TIER_A_BROKER`.
    2. Pin `broker/netjoin/join.go` as A in `tests/test_risk_tier.py`.
    3. Add `netjoin` to OPERATING §3's tier-A list.
  - The re-sign of that delta is one line.
  - This replaces the combined review's R1 (release). Issue draft r5 is not to be filed if this is fixed here.
- **R2 (release, tier A; childproc invariant, ARC-2, D-108).** The godbus exemptions are module-wide (`broker/childproc/gate_test.go:39`). The env exemption is checked only against agentosd's graph. Nothing pins D-108's claim that only `cmd/agentos-netjoin` imports godbus and uses only the system bus.
  - Failure path, reproduced: a session-bus call reaches `exec.Command("dbus-launch")` with the inherited environment, and the gates pass.
  - Fix:
    1. Add a test that the only non-test importer of godbus is `cmd/agentos-netjoin`, with no session-bus selector.
    2. Replace `wiring cmd/agentos-netjoin` (`broker/core/core.txt:44`) with `allow cmd/agentos-netjoin sockets.Server.* -- serves netjoin.sock (L8.3)`.
  - Issue draft: r6.
- **L3 (later, wording).** The comment in `core.txt` says "a separate root binary". Issue draft: l3.

Potency's l2 (#1216; no deadline on the helper's lookup and write) is not a Security finding. It affects availability only, and only root agentosd can reach the helper.

These existing rows are not repeated here: #933 (busconfig, r1), #935 (PSK at rest, r3), #936 (station device, seat and polkit facts, r4) and #926.

Next: fix B1 on #1214, then a one-line Security re-sign, then merge on green CI. File R2 (r6) as `class:release`.
