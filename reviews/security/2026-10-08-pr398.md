Threat check (adversary: a guest agent probing for host paths, IDs or canaries through error text; asset: host-side values, RES-4 / CAP-8):

- [Fact] **Closed set of Args.** `Arg`'s method `guestArg` is unexported, so only `Num`, `Guest` and types that embed one of them satisfy it. A method of the same name declared in another package has a different identity, so it does not satisfy the interface. `Newf` prints only what `guestArg()` returns: `int64(n)` for `Num`, and for `Guest` either the value checked against `guestRE` or the fixed "(not shown)". Fields of an embedding type, and any `String`/`Format` method it has, are no longer seen by `fmt`, because `fmt` gets a plain `string`/`int64`.
- [Fact] **The embedding bypass is closed.** At cec4407, `a.(Guest)` missed `struct{ Guest }`, and `%s` printed `{/var/lib/agentos-canary-7f3a/state/journal.db}`. With `guesterr.go` reverted to cec4407 and the new test kept, `TestAnEmbeddedGuestValueIsCheckedToo` fails with exactly that text. At 5ed5175 it passes.
- [Fact] **Callers.** Production `Guest(...)` callers are `guest/mcp.go:298,350` (request_id), `guest/mcp.go:354` (tool name, clipped to 64 with "…", which the regexp rejects), and `question/tool.go:128` (request_id). All are guest-sent values. No type in the tree embeds `Guest`. `Num` callers pass constants or `len(...)`, and a number cannot carry a path.
- [Fact] **Format string.** It is still a `Literal` (untyped constant). `TestToolErrorsAreBuiltOnlyFromSafeText` passes. Any wrong verb for a returned value prints `%!s(int64=3)`-style text, which shows nothing from the host.
- [Fact] **Filter path unchanged.** `Filter` still passes only `GuestText()` of a direct `Safe` and turns everything else into a ref.
