## Points

1. **blocker (defect; invariant P3-4b-3r-env-r8, CI red).** `agentos-seller` calls `os/exec` directly, with no `Env`. Two deterministic test failures, both reproduced locally on e8de182:
   - `childproc` `TestOnlyChildprocStartsAProcess`: `cmd/agentos-seller -> os/exec`.
   - `daemon` `TestEveryChildGetsAnExplicitEnvironment`: `prep.go:lookup`, `sealInto` and `checkSealed`.

   Fix: start debugfs and e2fsck through `childproc.Command(ctx, childproc.NewEnv("PATH=/usr/sbin:/usr/bin:/sbin:/bin", "LANG=C"), childproc.Options{Dir: ..., Stdin: ...}, ...)`, and add no exemption. `LANG=C` also pins the `ls -p` output that `lookup` parses.
2. **later.** LATER row `SELLER-prep-1 l1` gives a tier-A security point the `later` class. OPERATING §2 allows that only for wording. Replace it with a pointer on the FLASH-1 row, which is queued after G1 per D-104 and already owns signed-image verification.
3. **later.** `preflight` accepts an existing `/var/lib/agentos` without checking its mode or owner. The tmpfiles `d` line fixes both at boot, and `mkosi.finalize` keeps the directory empty.
