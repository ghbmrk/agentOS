### What changes for an attacker
- `ownerForget.Reconcile` now starts the take-back itself for an interrupted item 2 (`f.resume`).
- Follow's Reconcile can answer `not_applied`, which lifts the broker-account fence.
- STATUS gains an "unconfirmed" line built from executor names, and loops gains a fixed reply for a fenced setting.

None of this adds a guest path. Evidence still comes from broker-held state. `Resolve` still refuses unknown and has no owner caller.
