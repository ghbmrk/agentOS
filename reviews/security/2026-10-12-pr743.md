Threat model:
- Assets: main's merge gates, the Actions token's write scopes, and the integrity of BOARD.md (agents pick work from it) and the frozen archives.
- Adversaries: an outsider who opens or labels issues, a collaborator's or agent's careless issue edit, and a PR that tries to switch a check off.

| Path | Stop | How |

Findings:
- **S-l1 (later, `recheck`).** `board.py archive` and `check --repo` run from the PR's own checkout, and `tools/board.py` is tier C. A PR that rewrites `archive()` to return `[]` is judged by the rewritten function and needs only an L3. That weakens D22's line that "retiring the generated board takes a `ci.yml` change, which is tier A", and it weakens D24's freeze. Fix: run the base commit's `board.py` for these two steps (as D23 does with `ci_scope.py`), or add `tools/board*` to tier A. This is outside the cited IDs, so it is not a blocker.
- **S-l2 (later).** In `ci.yml`, `--changed $(git diff --no-renames --name-only HEAD^1 HEAD)` is unquoted, so a path with spaces or glob characters splits or expands. Every case found fails closed, as a spurious archive hit; none gives a false pass. Use `git diff -z` with `xargs -0`, or let `board.py` call git itself.
- **S-l3 (later).** `metrics.collect_states` counts `state:` label events on any `work-item` issue without the author_association filter that `board.py` applies. An outsider issue that a template or triager labels could skew the escalation rate. This affects metrics only.
