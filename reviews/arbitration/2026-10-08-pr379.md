# Arbitration, PR #379 (UPD-b)

One tension: after a first-boot release falls back, the gate stays closed until a newer release is out (Security, UPD-3's "credentials never touch an outdated image") against setup finishing (UX).

- Cross-check: holding costs UX only on a rare path (a stable release that fails to boot on this hardware); opening costs the hard constraint UPD-3 states. No midpoint keeps both.
- Redesign lever: a newer release is the fix, and the vendor ships one for a release that fails to boot; the box retries on its own. An owner override would be a new row with a security review (F4).
- Decision: keep the hold. Not a fork for Mark: UPD-3 is explicit.
