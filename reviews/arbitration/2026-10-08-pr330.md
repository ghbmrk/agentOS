# Arbitration: #330, OSS-6 silent publishing over Tor

**Conflict.** OSS-6 makes publishing silent: no text, digest, or STATUS line mentions it. That is the UX lens's preferred default. But with Tor always on, the owner's network provider can see that Tor is in use, and that can draw attention in some networks or jurisdictions. The Security lens says the owner should know this before it happens.

**Resolution.** Mention it once, in a place the owner already reads. The onboarding defaults line (§8) already states "sharing on" (LOOP-0), and it now also says the sharing runs over Tor. "stop sharing" stays the opt-out and stops the Tor traffic with it. Publishing stays silent in texts, digests and STATUS, as OSS-6 says, and the owner-visible log and the local UI still show it.

**Why it dominates.**

| Lens | Effect of the resolution |
|---|---|
| Security | Improves. The owner can make an informed choice before any Tor traffic leaves the box. |
| UX | Neutral. It is one clause in a line that already exists, and adds no recurring text. |
| Potency | Neutral. The default stays on. |

**Escalated.** Nothing.
