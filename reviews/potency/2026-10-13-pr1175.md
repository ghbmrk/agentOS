# Potency: PR #1175 (CTRL-card-rot-wire)

Record: PR #1175 · package CTRL-card-rot-wire · head d8dae194e7e552c10d02d7dfbb5d71145b18b8a9

Verdict: accept

This is the tier A lens screen, Potency pass. The question was whether the change caps what the owner or the box can do without buying matching security or UX.

- **Gain.** REC-4 rotation now runs on a real box, from the phone, for any subset of the five parts. Before this PR, `localui.Config.Rotation` was never set, and the vault process had no op to hold or commit a rotation. The PR reuses `recovery.BeginRotate`/`Pending`, `card.Display`, the unlock socket and `UnlockClient`, and adds only glue.
- **ARC-2 kept without cost.** The BOARD row said "agentosd's display", but the display now lives in agentos-localui, which already talks to the vault process. agentosd still links no card code, and no new socket or peer was added.
- **The proof is proportionate.** Any part can be rotated with one code from the code generator, or with the recovery key when the generator is lost. Only the passphrase and recovery-key slots also ask for the current passphrase, which is what `recovery` needs to rewrap them. Nothing asks for more than the part needs.
- **Known caps, already filed.** A rotated Wi-Fi password does not reach the running access point (#1172, release). Lost-card rotation is not offered on the page (#1174, later). Sessions signed in under the old code generator stay live until they expire (#1173, later recheck). Until CTRL-card-vaultop (#1114) stores a card in the vault, begin answers "I keep no Owner Card", so the feature is dark on a real box until then. That is a dependency, not a cap this PR adds.
- **P-l1 (later).** The page is the only client of the rotation ops. A rotation started from the owner channel (CH-11) is not possible, and REC-4 does not ask for one. Not proposed.

Considered, not proposed: keeping the in-effect display alive so it can be shown again. The #1090 F1 re-sign chose to erase it, and the confirm proves the owner holds a copy.

Next: merge on green CI once L3, UX and Security accept this head. Owed: none from Potency.
