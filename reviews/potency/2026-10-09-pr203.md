- [Fact] The operator keeps the full OS error in the broker log, so no diagnosis is lost to the host side.
- [Inference] The one cost is the collapsed `ErrInboxFull` (L3 later, Security f1, UX point 1): it removes a distinction no caller uses today but that a "try again later" owner text or a replay back-off would need. Lifting it is cheap (wrap only the `persist` error) and has no security cost, since the sentinel carries no path. Covered by the UX later line; not raised again here.
