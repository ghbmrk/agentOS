### Potency findings

- **P-1, later.** `broker/cmd/agentos-egress/rotation.go:338` (`default:` branch of `commitRotation`): no test pins that a commit which failed with nothing written holds no permit. If someone added `hold()` there, agentosd could put a Wi-Fi password on the air that the vault never committed, and no test would fail. #1522's acceptance is still met: with no commit there is nothing to take (agentosd test). Add one row to `rotwifi_test.go` that has a commit fail with a 4xx or 5xx and no slot written, and asserts `ErrNoRotatedWiFi`. The lapsed-rotation branch (`errRotationLapsed`) should get the same row.
- **P-2, later.** `broker/cmd/agentosd/main.go:475`: the arguments `main` passes to `pageSocket` are not tested, so passing `""` for the verify socket survives. #1524 offered the helper as an accepted way out, and both flag defaults (`-ap-net`, `-owner-verify`) are non-empty, so this is a residual risk, not a defect.
- **P-3, later.** `broker/daemon/rotateapnet_test.go:34`: the daemon test counts calls to a fake hook. It does not read a rewritten `ap-net.json` through `Run`, which #1524's first "Do" bullet asked for. The two tests together (daemon → hook, `pageSocket` → file) do cover the chain, and the acceptance line ("all four mutants killed") is met.
- **P-4, later.** `broker/card/display.go:52` (`Noted`) and `:334`: no test in the card package covers them; only the localui tests do. C1 and C2 are killed there, but a test in the card package would keep the card package's behaviour pinned on its own.
