Reviewed at c05f2fd. Fresh session, from the diff, the brief and the cited IDs (CH-3, CH-7, CH-10, LOOP-9; CH-21 for voice). The builder's reasoning was not used.

- The owner gets a full path from the Loop 2 text to a resume: the text now says "It stays paused until you resume it on my Wi-Fi page." (and the cleared line says the same), the home page lists **Paused** among its pages, each card says what resuming lets run again and who paused it, and the one button is "Ask to resume", with a note that says where the approval goes and that the answer is texted. The old "my Wi-Fi page will offer that in an update" text promised a step that did not exist (the CH-12 kind in this README); this PR removes it.
- Every failure is fixed text with a next step: the box doesn't answer ("Nothing was asked. Reload to try again."), a stale or edited form (`stalePage`), and a pause that changed ("That grant is no longer paused as this page showed it. Reload the page."). Socket errors never reach the page (`TestThePausedPageAsksToResumeAGrant` checks a path-like error is not shown).
- The success reply says what happens next and where: "Asked to resume G3. It shows under Approvals shortly; approve it there with a code from your code generator." The text after apply says "Resumed G3. Text PAUSE G3 or REVOKE G3 to stop it.", which matches the "Added" text owners already know.
- Voice: the new Loop 2 lines and agentosd's replies are first person or subjectless. `TestNoThirdPersonSelfReference` is red at this head only at `daemon/daemon.go:162`, which the PR does not touch (#402 fixes it).

Points:
1. **release (CH-21c, already queued)** — two new owner-facing strings in packages the voice test still exempts are third person: `localui/paused.go` "The box isn't answering right now." and `grants/resume.go` `pausedBy` fallback "the box" ("Paused by the box."). CH-21c's sweep should take them with the rest of localui and grants; no change needed in this PR.
2. **later** — the Approvals line shows the pause's intent ID, e.g. "Paused by Loop 2 (loop2/pause/3f9a…)" or "(owner/pause/G3/1696…)". The ID has to stay in the item's Detail, since the code is bound through it, but a non-technical owner reads it as noise. When the wording is next touched, show the pause time beside the ID or move the ID to a muted line.
3. **later** — a refusal from the gate that is not "pause changed" (for example the ask landing as not pending) shows the "isn't answering" text, which names the wrong cause. Its next step (reload) still works, and no realistic case is known with the page up, so it stays later.
4. **later** — the card heading is the bare grant ID ("G3"). Owners know it from the "Added G3" text, but the heading could lead with what it does (the `What` line) and keep the ID second.
