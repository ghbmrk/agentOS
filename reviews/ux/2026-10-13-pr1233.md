## Round 1 at 4ca8171

- **B1 (blocker, ONB-3).** The list's options carry no `value` (broker/localui/pages.go:267).
  - A browser submits the option's text with leading and trailing whitespace stripped and inner runs collapsed.
  - So picking an SSID that has leading, trailing or double spaces joins a different name. The owner gets `saved`, and 90 s later the never-online note.
  - Fix: `<option value="{{.}}">{{.}}</option>`, plus a test that the exact name is rendered as the value.
  - The Security reviewer raised it. I class it blocker because it breaks the cited pick path, and when unsure between blocker and release OPERATING §2 says blocker.
- **R1 (release, A1; the builder classed it later).** Once #936 lands a station device, the box's own sticker-password setup network can be listed. It is then the strongest entry, and the `<select>` has no placeholder, so it is the preselected default.
  - Failure path: the owner types the home password and taps Join. The box saves a connection to its own setup network, answers `saved`, and shows the never-online note 90 s later.
  - Fix: drop the box's setup SSID from the list, and add a disabled "Choose your network" first option.
- **R2 (release, A1 and ONB-3; the builder classed it later).** No `RequestScan` is made (broker/netjoin/ASSUMPTIONS.md:20, N10).
  - On the M6 Ultra's single radio, which serves the setup network, the list is always empty until #936.
  - Failure path: every A1 Wi-Fi run types the SSID, and a typo shows only as the 90 s note.
  - Fix: a hardware check after #936 that the list fills. If it does not, add `RequestScan` (polkit `wifi.scan`, which needs a Security re-sign).
- **L1 (later; builder's item).** Names that contain a Cf character are not listed but can be typed (broker/netjoin/netjoin.go:174). Such names are rare, and the rule closes a bidi spoof.
- **G1.** Neither release item blocks G1. The router cable goes in at §8.1 step 1, and the Ethernet button and the typed name reach the number step as before.
- **No finding.**
  - The "Not listed? Type its name" label is plain.
  - A typed name wins over the selection, as AT7 specifies.
  - An empty list gives exactly the pre-PR step.
