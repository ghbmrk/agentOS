## Security

Verdict: accept

Tier B combined pass, from `git diff origin/main...pr421` and CRED-1..7, CRED-5, CH-10, CH-11, UPD-4, REV-2. Questions: does any change let a credential reach the model, or let a remote party widen authority?

- (a) Pausing with no code moves only in the safe direction. A forged pause costs availability, not authority.
- (b) Resume widens authority again, so a code (CH-10, CH-11) and a consent re-ask for unconfirmed routes are right.
- (c) A signed notice that can only pause also moves in the safe direction. If the signing key is compromised, the worst case is a fleet-wide pause onto fallback routes, which costs money and availability but grants nothing. Recommend yes.
- (d) A response that matches no declared shape keeps the route down until a release, and no owner resume can lift it. This is right: it is the case where a credential might be leaking (Invariant C).
- (e), (f), (g): agreed. Errors are not withdrawal evidence, refusals are declared statuses, there is no auto-retry after a refused login, and fallback points to CAP-9.

Points:
