## Security
Verdict: accept. Threat check: the adversary is a hostile or confused guest reading `Stopped.Why`; the asset is host layout (journal and vault paths). `brokerRefused` drops the error text whenever it holds `/` or `\`, so a path from the broker or journal never reaches the model. This is structural for the stated threat: the cut is made in the one place the effect error enters `Why`. The other `Why` sources (`Bind`, `Fill`, run_id check) are in-package validation texts about the model's own arguments, not OS errors. Residual: the rule is a denylist on error text, so a host name or a bare file name with no separator would pass. That is a `later` item, not a blocker, because no such error source exists today.

## Potency
Verdict: accept. The model loses only the path detail, and a path-free reason is kept (`down`), so it can still tell a broker refusal from a precondition failure. Cost is nil.
