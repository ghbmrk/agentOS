Generated by `python3 summarize.py <runs-dir> <runs…>` from the raw run directories. The raw logs (strace, `broker.jsonl`, request bodies, guest state) are 40+ MB per run and are not committed. The directories below were still on disk when this file was generated.

**Configs.**
- `r1`, `r2`, `r_exec` used the first, minimal config (provider + MCP + update/telemetry/mDNS off).
- Every other run used the hardened [`openclaw.json5`](openclaw.json5) as committed. `loop1`, `gp1` and `gp2` used the committed scripts.
- `g1`–`g5` and `h_*` used earlier script versions that differ only in measurement:
  - `g1` traced the system resolver, with no DNS sink;
  - `g2`–`g4` measured RSS while leftover gateways from earlier runs were still alive, so their RSS figures are wrong;
  - in `h_*`, only `connect()` was traced.

**Columns.**
- *connect() destinations* counts every IPv4/IPv6 `connect()` by any process in the guest, including UDP DNS. A DNS lookup in the CLI runs would show up there as `…:53`.
- *DNS queries* lists query names, decoded from the DNS sink log or from the packets strace saw sent. "not traced" means names weren't captured; the connect column still shows whether a lookup was attempted.
