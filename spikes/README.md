# Spikes

Each spike answers one yes/no question from BOARD.md with measurements, then proposes a SPEC.md diff.

Layout: `spikes/<ID>-<slug>/` containing
- `QUESTION.md`: the question, the kill/pivot rule (from PLAN.md §3), and the time box.
- scripts and raw measurements;
- `RESULT.md`: yes/no, numbers, surprises, the proposed spec diff, and model usage spent.
